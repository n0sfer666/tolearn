# Контекст проекта tolearn

Локальное десктоп-приложение для обучения по программам (бандлам), которые
генерирует LLM. Уже сгенерированное работает офлайн, генерация требует сети;
без аккаунтов, ключей и платных функций.
Экзаменует LLM, но через копипаст: промпт копируется в любой чат, вердикт
вставляется обратно.

Что это и зачем — [README.md](../README.md) в корне. Здесь только то, что нужно
агенту для работы и чего нет в корневых документах.

## Языки документации

Пользовательская документация двуязычна и живёт зеркальными деревьями
`docs/ru/` и `docs/en/` (`guide`, `release`, `protocol`,
`install/*`); корневой `README.md` — английский, `README.ru.md` — русский.
Правишь одну локаль — правь пару в том же коммите: `app/tests/docs.rs` держит
зеркальность, шапку `**Русский** · [English](…)` и то, что ни одна ссылка в
`docs/` не ведёт в пустоту. Всё внутреннее (`architecture.md`, `fields.md`,
`adr/`, `specs/`, `design/`, `schemas/`, `manual-test-cases/`) остаётся русским
и лежит на месте.

## Как ведётся работа

Строго по спекам, по критическому пути, по порядку. TDD: тест пишется до кода.
Спека закрыта только когда её DoD проверен **запуском**, а не рассуждением.
Текущее состояние — [progress.md](progress.md).

## Правила, которые не пересматриваются без слова пользователя

1. Rust-ядро + Tauri 2; UI — статическая Astro MPA + острова SolidJS. Никакого
   SPA-роутера, никакого SSR, никаких шрифтов по сети — шрифт по сети запрещён,
   одно локальное семейство в дистрибутиве разрешено
   ([ADR-019](../docs/adr/019-local-app-font.md)).
2. `core` не знает про Tauri и UI; `offline` не знает про Tauri. Направление
   зависимостей — только вниз.
3. Никаких SDK, аккаунтов, ключей и платных функций — ни для чтения, ни для
   генерации. Уже сгенерированное открывается без сети, ключа и модели.
   Генерация карты и этапов требует сети всегда, даже с локальной моделью, и
   проверяет её до вызова модели; «Уточнить» и проверка ответа требуют
   провайдера (локальная модель считается), а сети — только с удалённым.
   Тесты сети не видят никогда (фикстуры вместо запросов).
4. Бюджеты из [architecture.md](../docs/architecture.md#бюджеты) — это тесты,
   а не пожелания. Числа ужесточаются по замерам, не ослабляются.
