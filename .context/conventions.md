# Конвенции

Источник правды по стилю — конфиги линтеров в репозитории. Здесь то, что из
конфига не следует.

## Rust

- Edition 2024, версия toolchain пиннится `rust-toolchain.toml`.
- Форматирование — `cargo fmt`, настройки по умолчанию. Спор о стиле решает
  форматтер, не человек.
- `cargo clippy --all-targets -- -D warnings`: предупреждение = ошибка.
  `#[allow(...)]` — точечно, на минимальной области, с комментарием-причиной
  (единственное разрешённое исключение из запрета на комментарии).
- `unsafe` запрещён: `[workspace.lints.rust] unsafe_code = "forbid"`, каждый крейт
  наследует набор через `[lints] workspace = true`. Собственных `[lints]` у крейта
  быть не должно — это проверяется тестом `cli/tests/layering.rs`.
- `unwrap()`, `expect()`, `panic!`, `todo!`, `dbg!` — линт держит их вне
  боевого кода; в тестах разрешены через `clippy.toml`. Ошибка возвращается
  типом, а не паникой.
- Ошибки: `thiserror` в библиотечных крейтах (`core`, `runner`, `offline`),
  `anyhow` допустим только на границе `cli`/`app`. Ошибка ядра доезжает до UI
  как **код + сообщение**, не как строка паники.
- Паника в библиотечном коде недопустима: файлы бандла пишет LLM, любой вход
  считается враждебным.
- Публичные типы бандла живут в `core`. Дублировать структуру YAML в других
  крейтах нельзя.
- Имена: модули и файлы `snake_case`, типы `CamelCase`. Один тип с
  ответственностью — один файл (правило 6 глобального CLAUDE.md).

## TypeScript / Astro / Solid (с S26)

- Строгая типизация: без `any`, без `as`, без `@ts-ignore`.
- Никакого клиентского роутера: переход — `<a href>`. Остров создаётся **только**
  там, где есть состояние; текст, списки, таблицы — статический HTML.
- Типы IPC не пишутся руками: генерируются из контракта S25.
- Веб-шрифтов нет. Системный стек.

## CSS

- `docs/design/tokens.css` — единственный источник дизайн-значений и
  подключается напрямую; копий не создаётся.
- Хардкод hex, px и чисел брейкпойнтов вне токенов запрещён линтом (S27).
- Именование токенов: шкала — семейство с префиксом (`--color-*`, `--spacing-*`,
  `--font-size-*`, `--radius-*`, `--z-*`, `--breakpoint-*`); одиночный токен —
  одно слово по смыслу (`--measure`, `--duration`). Семейство заводится, когда
  членов становится двое, а не заранее.
- Две темы — через `light-dark()`, каждый токен пишется один раз.
  Продублированная палитра запрещена: забытый в одной ветке токен молча ломает
  тему.
- `outline: none` без замены запрещён; цвет фокуса — только `--color-focus`.
- Вид живёт в общем слое `ui/src/styles/`, один файл — одна ответственность
  (`base`, `layout`, `controls`, `content`, `cards`, `status`, `practice`), все
  подключаются в `Base.astro`; стилей внутри островов нет. Порядок подключения
  значим: при равной специфичности выигрывает подключённый позже.
- Зацепка стиля — существующий `data-*` из разметки острова, а не новый класс.
  Astro оборачивает остров в `<astro-island>`, поэтому дочерний комбинатор к
  корню острова не доходит — селекторы потомковые.

## Текст интерфейса и документации

- Все пользовательские строки — через i18n с S28. Захардкоженная строка на
  экране роняет тест.
- Документы в `docs/` и `.context/` — по-русски. Код, коммиты, имена
  идентификаторов — по-английски.

## Чего не делаем

- Не рефакторим соседний код по ходу задачи.
- Не добавляем зависимость, которой не требует текущая спека.
- Не пишем комментарии (кроме причины у `#[allow]` и явной просьбы).
- Не расширяем спеку по своей инициативе: не влезло в DoD — это другая спека.
