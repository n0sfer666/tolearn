# Конвенции

Источник правды по стилю — конфиги линтеров в репозитории. Здесь то, что из
конфига не следует.

## Rust

- Edition 2024, версия toolchain пиннится `rust-toolchain.toml`.
- Форматирование — `cargo fmt`, настройки по умолчанию. Спор о стиле решает
  форматтер, не человек.
- `cargo clippy --all-targets -- -D warnings`: предупреждение = ошибка.
  `#[allow(...)]` — точечно, на минимальной области, с комментарием-причиной
  (единственное разрешённое исключение из запрета на комментарии).
- `unsafe` запрещён: `[workspace.lints.rust] unsafe_code = "forbid"`, каждый крейт
  наследует набор через `[lints] workspace = true`. Собственных `[lints]` у крейта
  быть не должно — это проверяется тестом `cli/tests/layering.rs`.
- `unwrap()`, `expect()`, `panic!`, `todo!`, `dbg!` — линт держит их вне
  боевого кода; в тестах разрешены через `clippy.toml`. Ошибка возвращается
  типом, а не паникой.
- Ошибки: `thiserror` в библиотечных крейтах (`core`, `runner`, `offline`),
  `anyhow` допустим только на границе `cli`/`app`. Ошибка ядра доезжает до UI
  как **код + сообщение**, не как строка паники.
- Паника в библиотечном коде недопустима: файлы программы пишет LLM, любой вход
  считается враждебным.
- Публичные типы программы живут в `core`. Дублировать структуру YAML в других
  крейтах нельзя.
- Имена: модули и файлы `snake_case`, типы `CamelCase`. Один тип с
  ответственностью — один файл (правило 6 глобального CLAUDE.md).
- Временный каталог теста берётся только из `tests-support/scratch.rs`
  (`scratch::made` — создать, `scratch::named` — только путь): всё ложится под
  один корень `<TMPDIR>/tolearn-tests/<pid>-<метка>`, и первое обращение в
  процессе сносит каталоги завершившихся pid. Прямой `env::temp_dir()` в тестах
  запрещён — это проверяется гейтом `cli/tests/scratch.rs`.

## TypeScript / Astro / Solid (с S26)

- Строгая типизация: без `any`, без `as`, без `@ts-ignore`.
- Никакого клиентского роутера: переход — `<a href>`. Остров создаётся **только**
  там, где есть состояние; текст, списки, таблицы — статический HTML.
- Типы IPC не пишутся руками: генерируются из контракта S25.
- Контекст экрана (`program`, `node`, `stage`) едет в адресе, а ссылки с `data-keep`
  дописывают его сами (`KeepContext.astro`). Последняя открытая программа
  запоминается в `localStorage["tolearn.program"]`. Поиск программы не требует:
  индекс один на всю библиотеку (S105), а находка сама несёт `program`, `node`,
  `stage` и якорь блока.
- Действие экрана для слоя «Действия» (⌘K, S149) объявляется атрибутом `data-action`
  на кнопке или ссылке: подпись — `aria-label`, иначе текст. `disabled`,
  `aria-disabled="true"` и всё внутри `hidden` или `inert` в слой не попадает.
  Пункты шапки слой берёт сам, текущий (`aria-current="page"`) пропускает. Слой
  зовут событием `tolearn:actions` на `window` — `summon()` из `lib/actions.ts`.
- Модальный слой строится одним способом — `layered()` из `lib/layered.ts`. Он даёт
  `keyed` (Esc закрывает, Tab и Shift+Tab ходят по кругу по стопам, событие выше не
  уходит — иначе тот же Esc поднимет и экран), `held` (фокус, ушедший из слоя,
  возвращается на первый стоп) и `aside` (клик по затемнению закрывает только при
  `event.target === event.currentTarget`). Стопы по умолчанию — `button`, свой набор
  идёт третьим аргументом (`Zoom.tsx` добавляет прокручиваемую рамку). Слушатель
  вешается как `on:keydown`, а не `onKeyDown`: делегата Solid ставит на `document`,
  где сидит `keys.ts`. Автофокус первой кнопки — `ref={grab}` из `lib/grab.ts`.
- Шапка — `components/Header.astro`, одна на все экраны через `Base.astro` (S150).
  `folded` сворачивает её на этапе: `nav` прячется стилем, но остаётся в DOM и
  в слое ⌘K. Кнопку `data-summon` обслуживает `lib/keys.ts` делегированным
  кликом, её `mousedown` гасится — в WebKit иначе поле слоя теряет фокус и слой
  закрывается до клика. Подсказку `data-chord` и `aria-keyshortcuts` ставит
  `shortcut()` по ОС. Название экрана в шапке подставляет `Names.astro` по
  событию `tolearn:name` (`name()` из `lib/name.ts`), виды — `program` и `stage`.
  Главное действие экрана кладётся в шапку слотом `action` (`slot="action"` на
  странице, `Base.astro` пробрасывает его в `Header.astro`) — вне `nav` разделов,
  с `data-action`; так в шапке библиотеки стоит «Новая программа» (S152).
- Клавиши — только через `lib/shortcuts.ts` (S151): обработчик спрашивает
  `pressed(event, id)`, а не сравнивает `event.key`/`event.code` с литералом;
  таблица на `/help/` строится из того же `SHORTCUTS`. Новое сочетание — строка в
  списке, текст в `i18n/shortcuts` и обработчик; `help.test.mjs` ловит сравнение
  мимо списка и сочетание без обработчика.
- В UI-тестах узел DOM не отдаётся в ассерт как `actual`: упавший
  `assert.equal(node, null)` заставляет репортер node:test печатать узел вместе
  с окном happy-dom — десятки ГБ памяти, SIGKILL, и оставшиеся тесты файла
  пропадают из отчёта без ошибки. Сравнивается булево: `assert.ok(node === null, …)`.
  Признак — `tests N` в отчёте меньше числа `test(` в файле.
- Шрифта по сети нет. Текст интерфейса и материала — одно локальное семейство
  в дистрибутиве (ADR-019); код — системный моноширинный стек.

## CSS

- `docs/design/tokens.css` — единственный источник дизайн-значений и
  подключается напрямую; копий не создаётся.
- Хардкод hex, px и чисел брейкпойнтов вне токенов запрещён линтом (S27).
- Размер, семейство и интерлиньяж — только токеном или `inherit`. Линт (S148)
  запрещает:
  - шорткат `font`;
  - время в `transition` и `animation`;
  - движение вне `@media (prefers-reduced-motion: no-preference)`.

  Кнопка меньше `--tap-target` получает зону `::after`. Кнопкой линт считает
  `a`, `button` и `summary` в селекторе и любой `data-*`, который в разметке
  `.tsx`/`.astro` стоит на таком теге. `summary` набрана высотой строки, 44 px
  ей даёт зона.
- Сетка и flex у `details` — только при `[open]`: закрытый `details` иначе
  держит место под спрятанное содержимое (`ui/tests/details.test.mjs`).
- Именование токенов: шкала — семейство с префиксом (`--color-*`, `--spacing-*`,
  `--font-size-*`, `--radius-*`, `--z-*`, `--breakpoint-*`); одиночный токен —
  одно слово по смыслу (`--measure`, `--duration`). Семейство заводится, когда
  членов становится двое, а не заранее.
- Две темы — через `light-dark()`, каждый токен пишется один раз.
  Продублированная палитра запрещена: забытый в одной ветке токен молча ломает
  тему.
- `outline: none` без замены запрещён; цвет фокуса — только `--color-focus`.
- Вид живёт в общем слое `ui/src/styles/`, один файл — одна ответственность
  (`base`, `layout`, `controls`, `content`, `cards`, `status`, `practice`), все
  подключаются в `Base.astro`; стилей внутри островов нет. Порядок подключения
  значим: при равной специфичности выигрывает подключённый позже.
- Зацепка стиля — существующий `data-*` из разметки острова, а не новый класс.
  Astro оборачивает остров в `<astro-island>`, поэтому дочерний комбинатор к
  корню острова не доходит — селекторы потомковые.
- Мимолётное сообщение («сохранено», «не удалось», «буфер недоступен») — только
  тост сверху через `ui/src/lib/toast.ts`: `ok` зелёный, `warn` жёлтый, `error`
  красный, `info` синий. Внутри острова такие строки не рисуются. Инлайном
  остаётся то, что живёт на экране: отчёт, конфликт, пустая выдача, вывод
  прогона.
- Шина тостов — событие на `window`, а не модуль-синглтон: тестовый харнесс
  собирает каждый остров отдельным бандлом, общий модуль между ними не един.
- Отказ IPC не проглатывается. Остров, который сам ловит ошибку, зовёт `quiet`
  и говорит словами; всё остальное идёт через `transport`, который сам покажет
  ошибку тостом. Опрос по таймеру на ошибке останавливается — иначе тост
  повторяется каждый тик.

## Текст интерфейса и документации

- Все пользовательские строки — через i18n с S28. Захардкоженная строка на
  экране роняет тест.
- Документы в `docs/` и `.context/` — по-русски. Код, коммиты, имена
  идентификаторов — по-английски.

## Чего не делаем

- Не рефакторим соседний код по ходу задачи.
- Не добавляем зависимость, которой не требует текущая спека.
- Не пишем комментарии (кроме причины у `#[allow]` и явной просьбы).
- Не расширяем спеку по своей инициативе: не влезло в DoD — это другая спека.
