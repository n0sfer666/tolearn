# Тестирование

Инструкции по домену: `~/wiki/knowledge/testing/systems.md` (Rust-часть),
`~/wiki/knowledge/testing/web.md` (`ui/`), `~/wiki/knowledge/testing/cli.md`
(команды `tolearn`), уровни — `~/wiki/knowledge/testing/tiers.md`.

## Порядок

TDD, без исключений: тест пишется **до** кода. Спека закрыта, когда её DoD
проверен запуском, а не рассуждением. Уровень проверки для каждой спеки уже
назначен в колонке «Проверка» [docs/specs/README.md](../docs/specs/README.md) —
он нижняя граница, а не потолок.

## Три правила, которые ломают сборку

1. **Ни одного сетевого запроса в тестах.** Всё, что приходит из сети,
   лежит фикстурой: сохранённые HTML-ответы, `llms.txt`, `robots.txt`. Прогон по
   живым сайтам — отдельный необязательный сценарий вне CI.
2. **Фикстуры не выдумываются по месту.** Основная — эталонный бандл
   `examples/llm-agents-base/`. Всё, чего в нём нет (история попыток, битые
   файлы, циклы, `paywall`, `video`, `paper`, `spec`), лежит в
   [fixtures/](../fixtures/README.md) — корпус S02 — и переиспользуется. Дубль
   фикстуры в тесте — ошибка ревью. Битая фикстура называется
   `<код>__<что сломано>.yaml` и даёт ровно одну ошибку валидатора — с тем кодом,
   что заявлен в имени.
3. **Бюджет — это тест.** Каждый порог из
   [architecture.md](../docs/architecture.md#бюджеты) закрепляется тестом,
   который падает при превышении: вес установщика, вес JS страницы, время
   импорта и открытия темы, холодный старт.

## Что где тестируется

| Слой | Как |
|---|---|
| `core` | unit-тесты рядом с кодом + `tests/` на фикстурах; вход — байты, выход — тип или ошибка |
| `runner` | интеграционные: таймаут, убийство дерева процессов, лимит вывода, закрытый stdin |
| `offline` | на сохранённых ответах; сеть замокана трейтом, не HTTP-моком |
| `cli` | сквозные вызовы бинарника на фикстурах: код возврата, `--json`, внятность сообщения |
| `ui` | сборка + гейт веса JS; линт токенов и контраста (S27) |
| экраны | T3: реальный запуск приложения, скриншот, проверка клавиатуры |

Битые фикстуры обязаны отвергаться с **разными** кодами ошибок: «не распарсилось»
— это не диагноз. Ошибка парсера несёт код (`ParseFailure`), строку и колонку;
тест утверждает код, а не подстроку сообщения — проза меняется, контракт нет.

«Парсер не пропустил ни одного поля» проверяется вычитанием, а не глазами: гейт
`gate::parser` по очереди выбрасывает из эталона каждое поле, описанное схемой, и
требует, чтобы разбор упал. Поле, которое парсер игнорирует, гейт называет по
имени. Так DoD S03/S04 опирается на тот же список полей, что и `docs/fields.md`,
а не на добросовестность автора теста. Два ограничения, из которых следует всё
остальное в этом разделе:

- Вычитание доказывает «поле **обязательно**», а не «значение **прочитано**»:
  парсер, который поле требует и выбрасывает, гейт не поймает. Что значение
  доехало, доказывают юнит-тесты по эталону (поле за полем, через полное
  разбиение структуры) и по валидным фикстурам — там лежат значения, которых в
  эталоне нет (непустой `calibration.passed_out`, например).
- Обрезание что-то доказывает только если необрезанный документ, прошедший тот же
  транспорт YAML→JSON→YAML, ещё разбирается. Поэтому гейт начинается с
  положительного контроля: сломанный транспорт делает такой цикл зелёным на пустом
  месте.

Полное разбиение структуры — не формальность: соседние поля одного типа
(`Material.title` и `Material.note`, `Check.check` и `Check.expect`) можно поменять
местами так, что и вычитание, и `.len()`-проверки останутся зелёными. Ловит это
только сравнение значения с эталоном, поэтому по одному представителю каждой
вложенной структуры разбирается целиком.

## Стенд для живой проверки (T3)

Экраны проверяются на связке «живое ядро + браузер», без сборки Tauri:

1. `cargo run -p tolearn-app --example bridge` — HTTP-мост на `127.0.0.1:4319`,
   тот же `ipc::call` и тот же `layout::places($HOME)`, что у настоящего
   приложения. `ui/src/lib/ipc.ts` в dev-режиме без `__TAURI_INTERNALS__` сам
   ходит в мост, поэтому UI работает на реальных данных.
2. `pnpm -C ui dev` — Astro на `localhost:4321`.
3. `scripts/shot.sh /ru/read/ shot.png 1100,1500` — снимок экрана headless
   Chrome; `out` с расширением `.html` вместо снимка выгружает DOM.

Мост держит порт, пока жив: перед перезапуском убивать старый, иначе
`порт занят`. Реестр приложения указывает на бандл `examples/llm-agents-base/`
прямо в репозитории — работа на стенде пишет в `examples/llm-agents-base/progress.yaml`,
это изменение в коммит не тащить.

## Что не автоматизируется и почему

Вердикт практики выносит человек ([ADR-006](../docs/adr/006-human-verdict.md)):
`expect` написан прозой, автоматическая проверка была бы враньём. Тестом
покрывается то, что раннер показал вывод рядом с ожиданием, а не то, что
ожидание выполнено.

Попадание модели в формат с первого раза (S43) недетерминировано и требует
ключа — ручной сценарий вне CI.
