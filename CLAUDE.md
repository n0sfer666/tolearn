# tolearn

Локальное приложение для обучения по программам, которые генерирует LLM:
уже сгенерированное работает офлайн, генерация требует сети.
Rust-ядро + Tauri 2, UI — статическая Astro MPA с островами SolidJS.

## Перед работой

Прочитать [.context/](.context/) — там карта проекта, конвенции, состояние работ.
Реализация идёт строго по спекам из [docs/specs/README.md](docs/specs/README.md),
по критическому пути, по порядку. TDD: тест пишется до кода; спека закрыта, когда
её DoD проверен запуском.

## Команды

```
cargo check --workspace --all-targets
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
```

Всё это разом — `make dev` (список берётся из `.context/checks.json`).
Собрать и поставить себе на macOS — `make install`.
Почистить `target` от старья — `make clean-target` (порог в сутках — `DAYS=30`).

Полный список и то, что появится позже, — [.context/checks.md](.context/checks.md).

## Долгие прогоны

Мутационный прогон, полный `cargo test --workspace`, сборка UI — в фон и **только**
с наблюдаемым логом и таймаутом:

- Вывод писать в файл построчно (`... > лог 2>&1`), без `| tail`/`| head` — они держат
  буфер до конца пайплайна, и прогон выглядит зависшим.
- На каждый внутренний шаг (одна мутация, один `cargo test`) — свой таймаут; на весь
  прогон — общий. Шаг вышел за таймаут: убить, пометить и идти дальше, а не ждать.
- Скрипт печатает прогресс (`N/M`) после каждого шага и флашит вывод.
- Прикидывать длительность заранее: одна мутация = полная пересборка задетых крейтов
  (~1 мин), двадцать мутаций — это полчаса. Не помещается — резать набор.

## Обратная совместимость

Строго: новая сборка открывает всё, что записала любая прежняя сборка v2, —
программы, `state.yaml`, настройки, журнал, пакеты — без потерь и без действий
человека. Меняешь структуру данных — одно из двух:

- спроектировать изменение поверх старой структуры: новое поле необязательное,
  его отсутствие даёт прежнее поведение; существующее поле не переименовывается
  и не меняет тип и смысл, обязательным задним числом не становится;
- если так нельзя — трансформер: версия в `schema` растёт, новая сборка читает
  и прежнюю версию и переводит её в новую при чтении, старое не теряется.

На каждое изменение формата — тест: данные в прежнем виде читаются новым кодом
и после записи ничего не теряют. Разрыв совместимости — только решением
владельца через ADR, как [ADR-016](docs/adr/016-v2-format-no-v1-compatibility.md)
для v1.

## Что нельзя

- Тащить в `core` знание про Tauri и UI, в `offline` — про Tauri.
- Ходить в сеть в тестах.
- Требовать сеть для уже сгенерированного (чтение, прогресс, практика — офлайн)
  или требовать аккаунт, ключ и оплату где бы то ни было, включая генерацию
  (локальная модель считается провайдером).
- Звать модель на генерацию карты или этапа, не проверив сеть: без сети
  генерация отказывает с причиной ([ADR-014](docs/adr/014-model-text-app-verified-sources.md)).
- Ослаблять бюджеты из [docs/architecture.md](docs/architecture.md#бюджеты).
- Выполнять `check`-команды из программы без явного действия человека.
- Писать в каталог содержимого программы (`<data>/programs/<uuid>/`) из чего-то,
  кроме генерации и импорта: пользовательское живёт в `<data>/state/<uuid>/`
  ([ADR-020](docs/adr/020-v2-program-library.md)).
