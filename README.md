# tolearn

**English** · [Русский](README.ru.md)

A local app for learning from programs generated by an LLM.

The LLM builds a learning program — a set of topics with materials, practice and
questions. `tolearn` shows that program, tracks progress and works entirely
without a network. The exam is still run by an LLM, but the app needs no
account, no key and no subscription: the prompt is copied into any chat and
the verdict is pasted back.

**Status: working.** Importing a program, topics, practice, the exam by
copy-paste and via a provider, the offline archive, Markdown export, the voice
exam and installers for macOS, Windows and Linux are all done.

## In progress (v2)

The second version will change how learning works:

- the app will generate a program itself, one stage at a time instead of all
  at once: theory together with practice, 2–4 hours per stage, 50–70 hours per
  program;
- after a stage there will be an optional written exam and up to three
  options for the next stage; when there is more than one, one is recommended;
- an unclear passage can be clarified: the explanation goes in as an insert
  after the paragraph;
- lessons will rely on sources the app checks itself, so generation will need
  a network even with a local model; already-generated material will still
  open without one;
- programs made with v1 will not open in v2.

A new interface design and sharing programs through export and import are in
the works too.

## Installation

Download the installer for your OS from the
[releases page](https://github.com/n0sfer666/tolearn/releases) and follow the page
for your system:

- [macOS](docs/en/install/macos.md) · [Windows](docs/en/install/windows.md) ·
  [Linux](docs/en/install/linux.md)
- [Building from source](docs/en/install/source.md) — for any other platform
- [Which variant to download](docs/en/release.md) — `tolearn` or
  `tolearn-with-speech`

The installers are unsigned, so macOS and Windows warn about an unverified
developer; how to get past that is on the page for your OS.
