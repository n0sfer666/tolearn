# tolearn

[English](README.md) · **Русский**

Локальное приложение для обучения по программам, которые генерирует LLM.

LLM строит программу обучения — набор тем с материалами, практикой и вопросами.
`tolearn` показывает эту программу, ведёт прогресс и умеет работать полностью
без сети. Экзаменует по-прежнему LLM — но приложение не требует ни аккаунта,
ни ключа, ни подписки: промпт копируется в любой чат, вердикт вставляется
обратно.

**Статус: работает.** Импорт программы, темы, практика, зачёт через копипаст и
через провайдера, экспорт в Markdown, голосовой зачёт и установщики под macOS, Windows и Linux — готовы.

## В работе (v2)

Вторая версия изменит саму модель обучения:

- программу будет генерировать само приложение — не целиком заранее, а по
  этапу за раз: теория вместе с практикой, 2–4 часа на этап, 50–70 часов на
  программу;
- после этапа — необязательный письменный зачёт и до трёх вариантов
  следующего этапа; если их несколько, один будет рекомендован;
- непонятный кусок текста можно будет уточнить: объяснение ляжет врезкой
  после абзаца;
- материал будет опираться на источники, которые приложение проверяет само,
  поэтому генерация будет требовать сети даже с локальной моделью; уже
  сгенерированное по-прежнему откроется без неё;
- программы v1 в v2 не откроются.

Ещё в работе — новый дизайн интерфейса и обмен программами через экспорт и
импорт.

## Установка

Скачайте установщик для своей ОС со
[страницы релизов](https://github.com/n0sfer666/tolearn/releases) и действуйте по
странице своей системы:

- [macOS](docs/ru/install/macos.md) · [Windows](docs/ru/install/windows.md) ·
  [Linux](docs/ru/install/linux.md)
- [Сборка из исходников](docs/ru/install/source.md) — для остальных платформ
- [Какой вариант скачивать](docs/ru/release.md) — `tolearn` или
  `tolearn-with-speech`

Установщики не подписаны, поэтому macOS и Windows предупредят о непроверенном
разработчике; как пройти предупреждение — на странице своей ОС.
