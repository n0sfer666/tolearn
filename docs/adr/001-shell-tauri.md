# ADR-001. Оболочка: Tauri 2

Rust-ядро + системный WebView.

Отвергнуто: **Electron** (100+ МБ Chromium в каждой сборке, противоречит
ограничению 5), **нативный UI на egui/iced** (пришлось бы руками рисовать
типографику для длинных учебных текстов — это то, в чём HTML силён, а
immediate-mode GUI слаб), **Flutter** (свой рендерер, +20 МБ, Rust-ядро пришлось
бы дёргать через FFI).

Мобильные приложения делаются позже на этом же ядре: Tauri 2 умеет iOS/Android.
Ядро (`core`) не должен знать ни про Tauri, ни про UI — это условие переиспользования.
