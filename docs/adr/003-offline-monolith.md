# ADR-003. Офлайн: monolith как библиотека + собственный WebView как рендерер

Подробности — [offline.md](../offline.md). Кратко:

- Статьи, доки, спеки → [monolith](https://github.com/Y2Z/monolith) (Rust, CC0,
  используется как библиотека) инлайнит CSS, картинки и шрифты в один HTML.
- Ограничение monolith — у него нет JS-движка, страницы с клиентским рендерингом
  сохраняются пустыми. Решение: у Tauri **уже есть** WebView. Открываем скрытое
  окно, ждём загрузку, забираем `document.documentElement.outerHTML`, и уже этот
  результат отдаём monolith. Ноль новых зависимостей.

Важное следствие для слоёв. WebView живёт в `app`, а не в `offline` — иначе
`offline` начинает зависеть от Tauri, направление зависимостей разворачивается, и
`tolearn scan` перестаёт работать в CI без GUI. Поэтому `offline` объявляет трейт
`Prerenderer` (`url → отрендеренный HTML`), у которого две реализации: заглушка
«отдать исходный HTML как есть» в CLI и настоящая на WebView в `app`. Пререндер
таким образом остаётся необязательным улучшением, а не условием работы загрузчика.
- Читалка — `dom_smoothie` (порт readability).
- `type: repo` → `gix`, `clone --depth 1`.
- Целые сайты документации → сначала пробуем `llms.txt` и `.md`-варианты страниц,
  это самый чистый офлайн-формат; краулер — запасной путь.
- `liveness: paywall | login_required` в материалах — готовый фильтр «не тянуть».
