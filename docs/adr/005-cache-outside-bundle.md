# ADR-005. Кэш офлайн-контента живёт вне бандла

Бандл перегенерируется. Кэш — нет. Хранилище адресуется содержимым:

```
<app-data>/cache/objects/<sha256[0:2]>/<sha256>
<app-data>/cache/index.sqlite   url → sha256, type, fetched_at, size, etag
```

Один и тот же URL в трёх программах хранится один раз. Ревалидация по
`ETag`/`Last-Modified`. Бюджет диска с вытеснением по LRU, порог настраивается.
