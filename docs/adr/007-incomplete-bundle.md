# ADR-007. Незавершённый бандл — нормальное состояние

В примере `llm-agents-base` заявлено 23 темы, файлов — 7: этапы 2 и 3 помечены
`generated: false`. Это штатный режим генератора, а не битый импорт. Тема без
файла отображается как «ещё не сгенерирована» и не считается ни в знаменателе
прогресса, ни ошибкой.
