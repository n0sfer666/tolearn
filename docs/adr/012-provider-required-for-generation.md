# ADR-012. Провайдер нужен генерации, а не чтению

Ограничения 1–2 в [architecture.md](../architecture.md#ограничения-из-которых-всё-следует)
написаны для v1, где бандл целиком приходит снаружи и приложение только его
читает. В v2 приложение само генерирует каждый этап (ADR-013), и генерация без
LLM не работает — молчать об этом было бы враньём.

Разделение по действию:

| Действие | Провайдер | Сеть |
|---|---|---|
| Открыть бандл, читать материал, вести прогресс, проходить практику уже сгенерированного | не нужен — ни ключа, ни модели | не нужна |
| Сгенерировать карту программы или этап | нужен | нужна всегда, даже с локальной моделью ([ADR-014](014-model-text-app-verified-sources.md)) |
| «Уточнить» | нужен | только если провайдер удалённый |
| Проверить письменный ответ зачёта | нужен | только если провайдер удалённый |
| Скопировать промпт зачёта в чужой чат и вставить вердикт руками | не нужен — копипаст остаётся путём, не требующим от приложения ничего | приложению не нужна |

Провайдером считается и локальная модель (S63, подбор по железу) — требование
«без аккаунтов и ключей» не снимается им же: снимается только «без LLM вообще»
для операций, которые без LLM бессмысленны. Ключ и аккаунт не становятся
обязательными нигде, включая генерацию. Тесты сети по-прежнему не видят:
фикстуры вместо запросов, как и было.

Сеть генерации проверяется до вызова модели: нет сети — генерация отказывает
с причиной и не тратит вызов. Как отказ выглядит в интерфейсе — группа D.

Ограничения переписаны:

1. Приложение не имеет права требовать сеть для уже сгенерированного: чтение,
   прогресс и практика работают офлайн. Генерация карты и этапов требует сети
   всегда, даже с локальной моделью, и проверяет её до вызова модели
   ([ADR-014](014-model-text-app-verified-sources.md)); «Уточнить» и проверка
   письменного ответа требуют провайдера, а сеть — только если провайдер
   удалённый.
2. Приложение не имеет права требовать аккаунт, ключ или оплату — ни для
   чтения, ни для генерации: локальная модель считается провайдером наравне с
   платным, ключ и аккаунт не становятся обязательными.
