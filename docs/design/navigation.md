# Навигация и структура

## Три уровня

```
Программы  →  Программа  →  Этап
```

Глубже не идём: подпрограмма открывается тем же экраном программы. Каждый
уровень — отдельная HTML-страница, переход — обычная ссылка (ADR-002).

## Стартовый экран — всегда список программ

Даже с одной программой. Список — это место, где видно, где ты находишься по
всем направлениям сразу; открывать сразу последнюю программу означает потерять
этот обзор.

Карточка программы: название, предмет, полоса прогресса, количество пройденного
из сгенерированного, дата последней активности. Несгенерированные этапы в
знаменатель не входят (ADR-007) — иначе прогресс выглядит вечно провальным.

Импорт — на этом же экране: зона перетаскивания и кнопка выбора файла
`.tolearn` дают одинаковый результат.

## Экран программы

Цель, уровень и объём по карте, затем лента этапов сверху вниз и
подпрограммы. Этап, который ещё не сгенерирован, виден с пометкой «ждёт
генерации». Чекпойнт визуально отделён от обычных этапов: он про весь
отрезок пути, а не про один шаг.

## Экран этапа

Блоки этапа в порядке программы: текст, код, схемы и картинки с лицензией,
практика и вопросы. Практика и вопросы пока только читаются: запуск проверок и
зачёт вернутся поверх формата v2, на крейте `runner` и протоколе из
[protocol.md](../ru/protocol.md).

Ограничения (`constraints`) и приёмка (`acceptance`) — две разные коллекции и
показываются раздельно: первое про форму решения, второе про результат
(ADR-006). Свести их в один список — значит потерять различие, вокруг которого
строится разговор на зачёте.

## Клавиатура

Приложение полностью управляется с клавиатуры. Фокус видим всегда. `Esc`
возвращает на уровень вверх. Поиск — по `/`.
