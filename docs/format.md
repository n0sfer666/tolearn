# Формат программы v2

Справочник полей программы v2, её этапов и состояния. Форму описывают три
схемы: [`tolearn/program/1`](schemas/program.schema.json),
[`tolearn/stage/1`](schemas/stage.schema.json) и
[`tolearn/state/1`](schemas/state.schema.json). Эталон —
[`examples/chiptune/`](../examples/chiptune/), корпус фикстур —
[`fixtures/v2/`](../fixtures/v2/). Почему формат такой —
[ADR-020](adr/020-v2-program-library.md).

```
<uuid>/
  program.yaml        цель, уровень, карта, источники, контекст генерации
  stages/<id>.yaml    этап листа: блоки, практика, вопросы зачёта
  assets/             SVG и картинки, на которые ссылаются блоки
  children/<uuid>/    подпрограмма — такой же каталог
```

Узел держит подпрограммы (`map.children`), лист — этапы (`map.stages`), глубина
дерева — не больше трёх уровней. У листа файл `stages/<id>.yaml` появляется,
когда этап сгенерирован: строка карты без файла — этап, которого ещё нет.

## Блоки

Текст этапа — список блоков `{id, kind, text}`. `text` — Markdown для
`paragraph`, `heading` и `callout`, исходник для `code`, Mermaid для `diagram`
и подпись для `image`.

| `kind` | Поля кроме `id`, `kind`, `text` |
|---|---|
| `paragraph` | — |
| `heading` | — |
| `callout` | — |
| `code` | `lang` — язык подсветки |
| `diagram` | `asset` — готовая SVG-схема; Mermaid в `text` — её исходник |
| `image` | `asset`, `license`, `attribution`; `source` — откуда картинка, если не своя |

`id` блока — первые восемь шестнадцатеричных знаков хэша его текста
(`tolearn_core::block::id`, S97). Повтор текста внутри этапа получает суффикс по
порядку появления: `27e110c4`, затем `27e110c4-2`. Блоки этапа и блоки задания
практики (`practice.task`) — одна последовательность: общий текст в `blocks` и
в `task` даёт суффикс так же, как повтор внутри `blocks`.

## Что ловит схема, а что — чтение

Схема проверяет форму одного документа: обязательные поля, закрытые объекты,
типы, шаблоны `uuid`, `slug`, `id` и путей ассетов, длины строк, даты, диапазон
часов из двух чисел не меньше единицы. Каждое её правило пинит битая фикстура в
`fixtures/v2/broken/`.

Связи между значениями и файлами схема не выражает — их проверяет чтение
программы (S99, `tolearn_core::program`). Документы, которые схема принимает, а
чтение обязано отвергнуть, лежат в `fixtures/v2/strict/`, деревья с нарушением
между файлами — в `fixtures/v2/invalid/`. Чтение сообщает все нарушения
дерева, а не первое, и у каждого правила свой код:

- `program.block-id` — `id` блока не совпадает с S97 от его текста;
- `program.foreign-block-field` — у блока поле, которого нет у его `kind` в
  таблице выше;
- `program.block-without-asset` — у `diagram` или `image` нет `asset`;
- `program.unlicensed-image` — у `image` нет `license` или `attribution`;
- `program.missing-asset` — файла из `asset` нет в `assets/` той же программы;
- `program.hours-reversed` — у часов `min > max`;
- `program.node-with-stages` — у одной программы и этапы, и подпрограммы;
- `program.too-deep` — подпрограммы у программы третьего уровня;
- `program.duplicate-uuid` — UUID повторяется в дереве;
- `program.child-uuid-mismatch`, `program.stage-id-mismatch` — в
  `children/<uuid>/` лежит программа с другим UUID, в `stages/<id>.yaml` — этап
  с другим `id`.

Разбор, кроме того, отвергает `uuid`, `slug`, `id` строки карты и этапа не по
шаблону (`yaml.unknown-value`): из них собираются пути, и до проверки дерева
такое значение не доходит.

## Роли и пути

У каждого поля одна роль: **рендер** показывается человеку
или уходит в промпт и на поведение не влияет, **логика** влияет на статус,
порядок, знаменатель или запуск, **игнор** не читается. Путь пишется так, как
его строит гейт схем: `map.stages[].hours` — поле элемента массива. Полноту
таблиц проверяет `every_described_field_is_classified_in_the_field_list`.

## state.yaml

Состояние программы — всё, что сделал человек: `<data>/state/<uuid>/state.yaml`
([ADR-026](adr/026-learning-cycle.md)). Пишет его только приложение, целиком и
атомарной подменой; в `programs/<uuid>/` при этом не пишется ничего. Нет файла —
состояние пустое. Чужая `schema`, битый YAML или состояние другой программы —
отказ с местом ошибки, и файл не перезаписывается. Этап, которого больше нет в
карте, и врезка к исчезнувшему блоку остаются в файле: осиротевшее убирает
только человек.

| Поле | Роль | Почему |
|---|---|---|
| `schema` | логика | мажор версии контракта; чужой мажор — отказ чтения |
| `program` | логика | UUID программы; состояние другой программы не читается |
| `workdir` | логика | папка практики, которую выбрал человек |
| `stages` | логика | записи об этапах по ключу `<uuid узла>/<id>`: `id` этапа уникален только внутри узла; записи без `opened` — этап не начат |
| `stages.*.opened` | логика | дата первого открытия: этап начат |
| `stages.*.passed` | логика | этап пройден; проваленная попытка его не снимает |
| `stages.*.passed.on` | рендер | дата прохождения |
| `stages.*.passed.by` | логика | `exam` — зачёт сдан, `skip` — пропущен; сводка считает пропуски |
| `stages.*.ticks` | рендер | отмеченные пункты `constraints` и `acceptance`; на статус не влияют |
| `stages.*.answers` | рендер | черновики ответов по `id` вопроса |
| `stages.*.attempts` | рендер | попытки зачёта дословно |
| `stages.*.attempts[].on` | рендер | дата попытки |
| `stages.*.attempts[].by` | рендер | `written` — ответы проверены из приложения, `copypaste` — тем же промптом в чужом чате |
| `stages.*.attempts[].model` | рендер | модель-экзаменатор; у копипаста неизвестна |
| `stages.*.attempts[].per_question` | логика | вердикт по вопросам: зачёт сдан, когда у каждого `ok` |
| `stages.*.attempts[].per_question[].id` | логика | вопрос этапа |
| `stages.*.attempts[].per_question[].result` | логика | `ok`, `partial` или `miss` |
| `stages.*.attempts[].per_question[].missed` | рендер | что упущено в ответе; у незачтённого не пуст |
| `clarifications` | рендер | врезки-уточнения к блокам этапов |
| `clarifications[].stage` | логика | этап врезки тем же ключом `<uuid узла>/<id>` |
| `clarifications[].block` | логика | `id` блока; блока нет — врезка уходит в свёрнутый список в конце этапа |
| `clarifications[].excerpt` | рендер | начало текста блока на момент уточнения |

| `clarifications[].clear` | логика | человек отметил «понятно» |

## Пакет `.tolearn`

Пакет — zip, в корне которого лежат файлы программы: `program.yaml`,
`stages/<id>.yaml`, `assets/…` и `children/<uuid>/…` на всю глубину. Последней
записью идёт `manifest.json`:

```json
{
  "schema": "tolearn/package/1",
  "files": {
    "assets/voices.svg": "<sha256>",
    "program.yaml": "<sha256>"
  }
}
```

`files` называет каждую запись пакета, кроме самого манифеста, и её sha256 в
нижнем регистре; ключи отсортированы.

- В пакет едет только то, что читает проверка S99: карта, этапы из строк карты,
  ассеты и подпрограммы из строк `children`. `state/`, кэш источников, этап без
  строки в карте, скрытые файлы `assets/` (`.DS_Store`) не едут.
- Пакет детерминирован: записи в порядке имён, у каждой время 1980-01-01 00:00,
  права 0644, сжатие Deflate. Две упаковки одной программы дают один sha256
  архива, где бы ни лежал каталог и какое бы время ни стояло у файлов.
- Подпрограмма `children/<uuid>/` пакуется как самостоятельная программа: её
  файлы лежат в корне пакета.
- Программа, не прошедшая S99, не пакуется: отказ несёт код её причины
  (`library.invalid`, `yaml.wrong-type`, …). Файл, который не читается, —
  `package.unreadable` с путём; сбой записи архива — `package.unwritable`.

CLI: `tolearn pack <каталог> <файл.tolearn> [--json]`. Файл пакета внутри
каталога программы — отказ: туда пишут только генерация и импорт.

### Импорт

`package::import(файл, библиотека)` ставит программу из пакета в
`<data>/programs/<uuid>/`, `package::unpack(файл, каталог)` кладёт её файлы в
пустой или несуществующий каталог. Проверки у обоих одни и те же, по порядку;
первый отказ останавливает импорт, называет причину кодом и файл — путём внутри
пакета.

| Код | Когда |
|---|---|
| `archive.*` | распаковка защитами S48: не zip (tar.gz тоже отказ), путь наружу, ссылка, лимиты записей, размера и сжатия |
| `package.no-manifest` | нет `manifest.json` |
| `package.bad-manifest` | манифест не JSON или не файл, `files` не объект sha256, лишнее поле |
| `package.version` | `schema` не `tolearn/package/1` |
| `package.unlisted` | файл пакета, которого нет в манифесте |
| `package.missing` | запись манифеста без файла |
| `package.checksum` | sha256 файла не совпал с манифестом |
| код S99 | программа не читается или нарушает правила (`library.invalid`, `yaml.wrong-type`, …) |
| `package.unused` | файл в манифесте, который программе не нужен (`state/`, этап без строки в карте) |
| `package.unsafe-svg` | SVG не UTF-8, не XML, объявляет кодировку не UTF-8 или несёт управляющий байт; в нём `<script>`, `<foreignObject>`, `<iframe>`, `<embed>`, `<object>`, атрибут `on*`, `href`/`xlink:href` не на `#якорь`, `attributeName` на `href` у анимации, DOCTYPE со своими сущностями, инструкция `<?…?>` |
| `package.occupied` | `unpack` в непустой каталог |
| `package.unwritable` | временный каталог не создаётся (у `unpack` — нет родителя цели), не удаётся переименовать или записать файл |

Значения атрибутов SVG сравниваются после разворота сущностей: `h&#114;ef` —
то же, что `href`. Распаковка идёт во временный скрытый каталог рядом с целью
(`programs/.<pid>-<n>.unpack` у импорта, `.<имя>.<pid>-<n>.unpack` у `unpack`);
он создаётся `create_dir`, занятое имя даёт следующий номер. После отказа не
остаётся ничего: ни временного каталога, ни `programs/`, если его не было до
импорта. `unpack` требует существующего родителя цели и родителей не создаёт.
SVG проверяется весь, включая подпрограммы; `url()` в стилях не проверяется —
схему рисует только `<img>`, а он не исполняет скрипты и не ходит в сеть.

Пересечение любого UUID дерева пакета — корня, подпрограмм, строк `children` в
картах — с UUID программ библиотеки даёт копию: всё дерево получает новые
UUID v4, каталоги `children/<uuid>/` переименовываются, и результат импорта
`Imported { uuid, copy_of: Some(корневой UUID пакета) }` говорит, что добавлена
копия. UUID меняются точечно, по месту узла в YAML (в кавычках, без кавычек,
блочным скаляром), и программа перечитывается: старый UUID, оставшийся где-то,
— отказ `library.taken`. Оригинал не трогается. Без пересечения `copy_of` пуст,
и круг «упаковать → импортировать» возвращает ту же программу с тем же UUID.

CLI: `tolearn unpack <файл.tolearn> <каталог> [--json]` — те же проверки,
`manifest.json` в каталог не кладётся; отказ — код и причина, exit 2.

Приложение (S103) до этих проверок отвечает на то, что пакетом не является:

| Код | Когда |
|---|---|
| `package.folder` | каталог с `program.yaml`: программу сначала собирают `tolearn pack` |
| `package.v1` | каталог бандла v1 (`roadmap.yaml` или `roadmap.json`) или архив `.zip`, `.gz`, `.tgz` — программы v1 не открываются (ADR-016) |
| `package.foreign` | всё прочее: файл не `.tolearn`, каталог без программы |

Чтение программы из библиотеки отказывает кодами `library.absent` (нет
