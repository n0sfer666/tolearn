# Руководство пользователя

Коротко: как пользоваться приложением. Установка — в [README](../README.md).

## С чего начать

1. Получите программу обучения. Промпт для этого лежит в репозитории —
   [`core/assets/generate.md`](../core/assets/generate.md): скопируйте его в
   любой чат с LLM, ответьте на вопросы, заберите готовый бандл — папку с
   `roadmap.yaml`, `topics/*.yaml` и `examiner.md`. Пример —
   [`examples/llm-agents-base`](../examples/llm-agents-base). Кнопки «взять
   промпт» в интерфейсе пока нет.
2. На главном экране нажмите «Выбрать папку» или «Выбрать архив». Приложение
   проверит бандл и покажет ошибки, если они есть.
3. Откройте тему и начинайте.

## Экраны

| Экран | Зачем |
|---|---|
| Программа | все темы по этапам, статусы, точка входа в тему |
| Тема | материалы, практика, вопросы, конспект |
| Практика | таймер на таймбокс темы, переживает перезапуск |
| Зачёт | вопросы, ответы и вердикт |
| Очередь | что делать сейчас: доступные темы и подошедшие повторения |
| Повторение | темы, у которых наступил срок ревалидации |
| Устаревшее | темы, изменившиеся после перегенерации программы |
| Граф | зависимости тем по слоям |
| Конспекты · Поиск | все конспекты и поиск по ним |
| Статистика | часы, статусы, история |
| Настройки | язык, провайдер LLM, конспекты, шифрование, офлайн, история |

## Зачёт

Два пути, оба ваши:

- **Копипаст (по умолчанию).** Приложение собирает промпт, вы вставляете его в
  любой чат, ответ модели вставляете обратно. Ни ключа, ни аккаунта.
- **Провайдер.** В настройках можно указать Ollama (локально) или
  OpenAI-совместимый адрес с ключом. Ключ хранится в системном хранилище ОС.

Вердикт пишется в `progress.yaml` вашей программы. Больше приложение в бандл не
пишет ничего.

## Конспекты

Конспект темы — обычный `.md` с фронтматтером `tolearn: roadmap/topic`. По
умолчанию они лежат в данных приложения, но в настройках можно указать своё
хранилище — например, папку Obsidian: тогда правки снаружи подхватываются.

Шифрование (настройки → «Шифрование») закрывает **внутренний** каталог: файлы
становятся нечитаемыми снаружи, имена не выдают тему. Цена сказана прямо на
экране — внешний редактор, подхват правок снаружи и плагин Obsidian перестают
работать, а потеря и парольной фразы, и ключа устройства означает потерю
конспектов. Внешнее хранилище не шифруется никогда.

## Офлайн

Материалы темы скачиваются один раз и сохраняются целиком одним HTML-файлом.
После этого сеть не нужна: читалка показывает текст из архива. Ничего, кроме
явно запрошенной загрузки, в сеть не ходит.

## Плагин Obsidian

Показывает в строке состояния программу, статус открытой темы и «пора
повторить», а по команде открывает тему в приложении. Ничего не пишет. В
настройках плагина укажите каталог данных приложения. Статус показывается
записанный — блокировки и протухание пересчитывает приложение, поэтому точный
ответ всегда там. При включённом шифровании плагин статусы не видит и говорит об
этом.

## Где лежат данные

- Программы — там, где вы их положили; приложение помнит путь в реестре.
- Всё остальное (реестр, конспекты по умолчанию, архивы страниц, история версий,
  настройки) — в каталоге данных приложения ОС.
- Удаление приложения данные не трогает.

## Экспорт

Кнопка «Экспорт в Markdown» на экране программы собирает всю программу в один
файл — с оглавлением, темами, конспектами. Ответы и ловушки попадают в файл
только для зачтённых тем. Внутрь самого бандла экспорт не пишет.
