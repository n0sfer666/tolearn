# Импорт пакета `.tolearn` и чтение этапа

Автотесты импортируют пакет через подменённый диалог и рисуют экраны в
happy-dom. Настоящее перетаскивание, системный выбор файла, картинки в окне и
тёмная тема проверяются руками.

**Что нужно:** пакет эталона, собранный из репозитория:

```sh
cargo run -p tolearn-cli --release -- pack examples/chiptune ~/chiptune.tolearn
```

Для отказов — папка `examples/chiptune`, папка с одним файлом `roadmap.yaml`
(каталог v1, содержимое не важно) и любой `.zip`. Состояние перед прогоном — чистое (см. [README](../README.md)).

## Основной сценарий: пакет перетаскиванием

1) запустить приложение;
2) открыть экран «Программы»;
3) перетащить `~/chiptune.tolearn` в окно приложения.

ОР: на время импорта кнопка показывает «Импортирую…»; всплыло уведомление
«Программа добавлена: Chiptune: музыка звукового чипа NES»; в «Библиотеке»
карточка программы с целью и объёмом карты в часах («N–M ч»), пустой полосой
прогресса и «пройдено 0 из 1, без зачёта 0» — в знаменателе только
сгенерированный этап; даты последней активности нет, подпрограммы не раскрыты.

4) нажать на название программы.

ОР: экран программы — цель, уровень, объём по карте, список этапов: «Голоса
чипа» — ссылка, остальные этапы без ссылки, пунктиром и с пометкой «ждёт
генерации».

5) открыть «Голоса чипа».

ОР: этап нарисован целиком: заголовки, текст с разметкой, блок кода, выноска,
SVG-схема и PNG-картинка; под картинкой — лицензия, атрибуция и источник, под
схемой подписи нет; под блоками, кроме заголовков, — «Уточнить». Ниже — практика:
задание, результат, ограничения и критерии приёмки с галочками; строки «Папка
практики» и кнопок «Запустить» нет — у эталона нет команд проверки. Затем вопросы
зачёта с полями «Ваш ответ», «Сдать» и «Сдать через другой чат», в конце —
«Пропустить зачёт» и «Перегенерировать этап». Весь цикл по этим кнопкам —
[generate/05-cycle.md](../generate/05-cycle.md).

6) нажать Tab несколько раз, затем Esc.

ОР: фокус виден на каждой ссылке; Esc возвращает на экран программы, а не в
список программ.

## Ветка: тёмная тема

1) в «Настройках» выбрать тёмную тему;
2) открыть этап «Голоса чипа» снова.

ОР: текст, выноска, код и подписи читаются; схема и картинка видны на тёмном
фоне. Снять скриншоты этапа в светлой и тёмной теме.

## Ветка: выбор файла кнопкой и копия

1) на экране «Программы» нажать «Выбрать файл»;
2) в системном диалоге выбрать тот же `~/chiptune.tolearn`.

ОР: диалог системный и показывает только файлы `.tolearn`; отмена ничего не
меняет. После выбора всплыло «Такая программа уже есть — добавлена копия:
Chiptune…», в библиотеке две карточки; первая не изменилась.

## Ветка: не пакет

1) перетащить папку `examples/chiptune`;
2) перетащить папку с `roadmap.yaml`;
3) перетащить любой `.zip`;
4) перетащить любую другую папку (например, пустую).

ОР: импорт отклонён, в блоке причины — «Это папка, а нужен файл .tolearn —
соберите его командой tolearn pack» для первой папки, «Программы v1 не
открываются: нужен пакет .tolearn» для второй папки и архива, «Это не пакет
.tolearn» для последней. Ошибки разбора нет, библиотека не изменилась.

## Ветка: английский

1) в «Настройках» выбрать English;
2) открыть адрес этапа, которого нет (например, изменить `stage=` в адресе
   через перезагрузку окна после открытия этапа), или открыть программу, затем
   удалить её каталог из `~/.local/share/tolearn/programs/` и обновить экран.

ОР: причина написана по-английски, ссылка ведёт в список программ.
