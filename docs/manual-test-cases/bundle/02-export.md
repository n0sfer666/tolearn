# Экспорт программы в Markdown

Автотесты собирают страницы в ядре, пишут папку через IPC и CLI и гоняют
результат через markdownlint. Системный выбор папки, уведомление в окне и то,
как папка выглядит в чужом редакторе Markdown, проверяются руками.

**Что нужно:** в библиотеке импортированы `chiptune.tolearn` и пакет
`nes-dev`, собранные из репозитория:

```sh
cargo run -p tolearn-cli --release -- pack examples/chiptune ~/chiptune.tolearn
cargo run -p tolearn-cli --release -- pack fixtures/v2/valid/nes-dev ~/nes-dev.tolearn
```

Импорт — по [01-import.md](01-import.md). Пустая папка `~/Выгрузка` и любой
редактор с предпросмотром Markdown (VS Code, Obsidian).

## Основной сценарий: вся программа

1) открыть «Chiptune: музыка звукового чипа NES» из библиотеки;
2) нажать «Экспорт в Markdown»;
3) в системном диалоге выбрать `~/Выгрузка`.

ОР: диалог выбирает папку, а не файл; всплыло «Выгружено в
~/Выгрузка/chiptune»; в `~/Выгрузка/chiptune` лежат `index.md`,
`01-voices.md` и `assets/` с `voices.svg` и `pulse-wave.png`.

4) открыть `~/Выгрузка/chiptune` в редакторе Markdown и включить предпросмотр
`index.md`.

ОР: заголовок программы, цель, уровень, объём по карте; «Этапы» — «Голоса
чипа» ссылкой, остальные с пометкой «ждёт генерации»; внизу «Источники».

5) перейти по ссылке «Голоса чипа».

ОР: страница этапа целиком — текст, код, выноска, схема и картинка видны, под
картинкой лицензия и автор; ниже практика и вопросы, после вопросов строка
«Эталонные ответы не экспортированы: этап не зачтён.», самих ответов нет.
Ссылка «←» ведёт обратно в `index.md`.

## Ветка: подпрограмма

1) открыть «Разработка игр для NES», перейти в «Инструменты сборки», затем в
«Первый ROM»;
2) нажать «Экспорт в Markdown» и выбрать `~/Выгрузка`.

ОР: появилась `~/Выгрузка/first-rom` только с этой подпрограммой: в
`index.md` нет ссылки «←» наверх, картинка этапа открывается.

## Ветка: папка занята

1) снова открыть «Chiptune» и нажать «Экспорт в Markdown»;
2) выбрать ту же `~/Выгрузка`.

ОР: уведомление «Имя программы в выбранной папке уже занято файлом или непустой
папкой…»;
содержимое `~/Выгрузка/chiptune` не изменилось, лишних папок рядом нет.

## Ветка: отмена и библиотека

1) нажать «Экспорт в Markdown» и закрыть диалог без выбора.

ОР: ничего не происходит, уведомления нет.

2) нажать «Экспорт в Markdown» и выбрать папку `programs` внутри данных
приложения (путь — в [README](../README.md)).

ОР: уведомление «В библиотеку выгружать нельзя…»; в `programs` ничего не
появилось.

## Ветка: терминал

```sh
cargo run -p tolearn-cli --release -- export examples/chiptune ~/Выгрузка/cli
```

ОР: «выгружено в ~/Выгрузка/cli (файлов: 4)», код выхода 0. Повтор той же
команды — отказ с `export.occupied`, код выхода 2.
