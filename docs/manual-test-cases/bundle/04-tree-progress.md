# Прогресс по дереву программы

Автотесты считают сводку на фикстурах и рисуют экраны в happy-dom. Здесь одна
отметка проходит по всему дереву в собранном приложении: лист, подпрограмма,
корень и карточка библиотеки должны назвать одни и те же числа.

**Что нужно:** пакет многоуровневой программы, собранный из репозитория:

```sh
cargo run -p tolearn-cli --release -- pack fixtures/v2/valid/nes-dev ~/nes-dev.tolearn
```

Состояние перед прогоном — чистое (см. [README](../README.md)). Провайдер не
нужен: пропуск зачёта записывается до развилки, отказ развилки без провайдера
прогону не мешает.

## Основной сценарий

1) запустить приложение, перетащить `~/nes-dev.tolearn` в окно.

ОР: в «Библиотеке» карточка «Разработка игр для NES»: пустая полоса,
«пройдено 0 из 2, без зачёта 0», даты последней активности нет, подпрограммы
на карточке не перечислены.

2) открыть «Разработка игр для NES».

ОР: «Прогресс: пройдено 0 из 2, без зачёта 0»; в «Подпрограммах» у
«Инструменты сборки» — «пройдено 0 из 2, без зачёта 0», у «Звук и музыка» —
«ждёт генерации» и никаких чисел.

3) открыть «Инструменты сборки».

ОР: «Прогресс: пройдено 0 из 2, без зачёта 0»; у подпрограммы «Первый ROM в
cc65» — «пройдено 0 из 2, без зачёта 0».

4) открыть «Первый ROM в cc65».

ОР: этапы «Первый ROM» и «Конфиг компоновщика» — «не начат», «Прогресс:
пройдено 0 из 2, без зачёта 0», списка подпрограмм нет.

5) открыть «Первый ROM», в конце этапа — «Пропустить зачёт»; вернуться на
«Первый ROM в cc65» по пути в шапке.

ОР: у «Первый ROM» — «пройден» и «зачёт пропущен», «Прогресс: пройдено 1 из 2,
без зачёта 1».

6) по пути в шапке подняться на «Инструменты сборки», затем на «Разработка игр
для NES».

ОР: на обоих экранах «Прогресс: пройдено 1 из 2, без зачёта 1»; строка
«Первый ROM в cc65» и строка «Инструменты сборки» несут те же числа; «Звук и
музыка» по-прежнему «ждёт генерации» без чисел.

7) открыть «Программы».

ОР: на карточке полоса заполнена наполовину, «пройдено 1 из 2, без зачёта 1»,
«Последняя активность» — сегодняшняя дата.

## Ветка: перезапуск

1) закрыть приложение, запустить снова, открыть «Программы», затем
«Разработка игр для NES».

ОР: числа шагов 6 и 7 на месте, дата последней активности та же.

## Ветка: битое состояние

1) закрыть приложение; в `~/.local/share/tolearn/state/7a1d4e90-2c3b-4f58-8d6e-1b9a0c5e7f23/state.yaml`
заменить первую строку на `schema: tolearn/state/9`;
2) запустить приложение, открыть «Программы».

ОР: карточка «Разработка игр для NES» на месте, вместо полосы и сводки —
«Прогресс не читается: …» с причиной; файл состояния не переписан.

## Что записать в отчёт

- каждый шаг, где числа на экранах разошлись: номер шага, что видно, скриншот;
- текст причины из ветки «битое состояние».
