# Удаление программы в корзину

Автотесты гоняют удаление на подставной корзине: настоящую они не трогают.
Руками проверяется то, чего подмена не показывает: macOS не просит прав на
управление Finder, программа действительно лежит в корзине системы и
возвращается оттуда, а данные приложения после удаления чисты.

**Что нужно:** в библиотеке импортированы `chiptune.tolearn` и пакет
`nes-dev` (шаги — в [01-import.md](01-import.md)), журнал запросов включён в
настройках и в нём есть хотя бы один файл (см.
[../provider/04-journal.md](../provider/04-journal.md)). Корзина системы
открыта в отдельном окне. Путь к данным приложения — в
[README](../README.md).

## Основной сценарий: программа уходит в корзину

1) открыть «Chiptune: музыка звукового чипа NES» из библиотеки;
2) нажать «⋯» в шапке и выбрать «Удалить в корзину…».

ОР: поверх экрана слой подтверждения: заголовок «Удалить «Chiptune: музыка
звукового чипа NES»?», строка о том, что уходит, и строка о возврате из
корзины. Фокус на «Отмена», `Tab` ходит только между «Отмена» и «Удалить»,
⌘K и `/` слой не пробивают.

3) нажать «Удалить».

ОР: **системный запрос прав на управление Finder не появляется**, звука корзины
Finder нет. Открылась библиотека, карточки «Chiptune» в ней нет, всплыло
«Программа удалена: Chiptune: музыка звукового чипа NES».

4) посмотреть в корзину системы и в данные приложения.

ОР: в корзине лежат каталоги удалённой программы: её `<uuid>` из `programs`,
её `<uuid>` из `state` и `cache`, и папка `llm-log` целиком. В данных
приложения этих каталогов больше нет, каталоги `nes-dev` на месте,
`cache/index.sqlite` на месте.

5) перезапустить приложение.

ОР: в библиотеке только «Разработка игр для NES», её прогресс прежний.

## Ветка: возврат из корзины

1) перетащить каталог `<uuid>` программы из корзины обратно в `programs`
   данных приложения;
2) перезапустить приложение.

ОР: «Chiptune» снова в библиотеке. Прогресс пуст: `state` остался в корзине —
его при желании возвращают тем же перетаскиванием.

Пункта «Положить обратно» у корзины для этих каталогов нет: приложение
переносит их через `NSFileManager`, и macOS не записывает исходный путь
([THIRD-PARTY.md](../../../THIRD-PARTY.md)).

## Ветка: отмена

1) открыть «Разработка игр для NES» и выбрать «Удалить в корзину…»;
2) нажать `Esc`.

ОР: слой закрылся, фокус вернулся на «⋯», программа на месте. То же самое по
кнопке «Отмена» и по повторному вызову через ⌘K → «Удалить в корзину…».

## Ветка: подпрограмма

1) открыть «Разработка игр для NES» → «Инструменты сборки»;
2) открыть «⋯».

ОР: в меню только «Экспорт в Markdown»: удалять подпрограмму отдельно нельзя.

## Ветка: идёт генерация

1) открыть «Разработка игр для NES» → «Инструменты сборки» и нажать
   «Продолжить»: пойдёт генерация следующего этапа на живом провайдере
   (шаги — в [../generate/02-new-program-screen.md](../generate/02-new-program-screen.md));
2) не дожидаясь конца, вернуться на экран программы и выбрать
   «Удалить в корзину…», подтвердить.

ОР: уведомление «Идёт генерация этой программы — дождитесь её или отмените.»,
программа на месте, генерация не прервалась. После её конца удаление проходит
обычным порядком.
