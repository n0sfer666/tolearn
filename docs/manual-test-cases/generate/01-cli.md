# Генерация из терминала: `tolearn new` и `tolearn next`

Автотесты зовут заглушку модели и фикстурные страницы: живой провайдер, настоящая
сеть, время и токены шагов проверяются только руками.

**Что нужно:** провайдер модели, включённый и проверенный в «Настройках»
приложения ([provider/01-local-model.md](../provider/01-local-model.md)), сеть и
собранный CLI:

```sh
cargo build -p tolearn-cli --release
```

Дальше `tolearn` — это `target/release/tolearn`, а `~/tolearn-cli` — каталог
прогона, которого ещё нет.

С удалённым провайдером первый запуск читает ключ из связки ключей macOS, и
система спрашивает разрешение для `tolearn` — разрешить. Без графической
сессии (по ssh) спросить некому: команда отказывает «ключ провайдера не
прочитан». Локальная модель связки ключей не касается, вопроса не будет.

## Основной сценарий

1) выполнить `tolearn new "Хочу писать чиптюн" --level "Нот не знаю" --out ~/tolearn-cli`.

ОР: по ходу печатаются строки шагов — «карта», «источники», «текст», «схемы»,
«запись», у каждой время в секундах, у шагов с моделью — токены
`<вход> → <выход> ток.`; у строки «схемы» — «схемы остались исходником
Mermaid: окна для схем нет», если в этапе есть схема. В конце — три строки:
`программа: ~/tolearn-cli/programs/<uuid>`, `этап: <id> · …`,
`дальше: tolearn next ~/tolearn-cli`. В `~/tolearn-cli/cache/<uuid>/` лежит
`ledger.jsonl`, библиотека приложения не изменилась.

2) выполнить `tolearn next ~/tolearn-cli`.

ОР: строка «развилка · … с · … ток.», затем «развилка после этапа <id>:» и
пронумерованные варианты — id, название, часы, у одного «рекомендую», у каждого
причина после тире; в конце подсказка с `--choice <номер>`.

3) повторить `tolearn next ~/tolearn-cli`.

ОР: те же варианты мгновенно, без строки «развилка» — развилка взята из кэша.

4) выполнить `tolearn next ~/tolearn-cli --choice 1`.

ОР: строки шагов «источники», «текст», «схемы», «запись» и итог с id выбранного
этапа.

5) выполнить `tolearn pack ~/tolearn-cli/programs/<uuid> ~/tolearn-cli.tolearn`,
   запустить приложение и импортировать пакет
   ([bundle/01-import.md](../bundle/01-import.md)).

ОР: программа открывается, в ней два созданных этапа; схема, если была, показана
кодом Mermaid.

## Ветка: итог объектом

1) выполнить шаг 1 основного сценария с `--json` в новый каталог.

ОР: stdout — один JSON-объект с полями `program`, `path`, `node`, `stage`,
`title`, `ms`, `calls`, `input`, `output`, `unknown`, `mermaid`; строки шагов
по-прежнему идут в stderr.

## Ветка: занятый каталог

1) повторить шаг 1 основного сценария на `~/tolearn-cli`.

ОР: отказ «в `…` уже лежит программа: продолжай её через `tolearn next …`»,
модель не вызывалась, программа в каталоге не изменилась.

## Ветка: хранилище приложения

1) выполнить шаг 1 основного сценария с `--out ~/.local/share/tolearn/cli`.

ОР: отказ «… лежит в хранилище приложения …» сразу, модель не вызывалась,
каталог `cli` не создан.

## Ветка: без сети

1) выключить сеть;
2) выполнить шаг 1 основного сценария в новый каталог.

ОР: отказ с `generate.offline` сразу, каталог программы не создан.

## Ветка: выбор без развилки

1) в новом каталоге после шага 1 сразу выполнить `tolearn next <каталог> --choice 1`.

ОР: отказ «развилка после этапа «<id>» не открыта: сначала открой её», модель не
вызывалась.
