# Сборка программы живой моделью

Автотесты проверяют сборку на записанных ответах. Живая модель — единственный
способ увидеть, что план получается осмысленным, поток ответа доезжает до экрана,
расход токенов считается, а собранный бандл проходит валидацию.

**Что нужно:** настроенный и включённый провайдер (см. `provider/`), запас времени
— полная сборка идёт от нескольких минут до получаса.

## Основной сценарий

1) запустить приложение;
2) на экране «Программы» нажать «Собрать программу»;

ОР: открылось окно «Новая программа» с полями «Чему хотите научиться», «Уровень»,
«Часов в неделю», «Срок, недель».

3) в «Чему хотите научиться» описать тему своими словами (2–3 предложения);
4) выбрать уровень «Знаю основы», часов в неделю — 6, срок — 8 недель;
5) нажать «Собрать»;
6) смотреть на окно, пока идёт сборка.

ОР: показано «Составляю план», под ним меняющаяся строка занятия («Обдумываю»,
«Разбираю», …), строка «потрачено: N токенов» (или «провайдер не считает токены»
для харнесса без учёта) и хвост ответа модели, который прирастает по ходу.

7) дождаться готового плана.

ОР: показано «План готов», «Тем в плане: N» и кнопка «Продолжить».

8) нажать «Продолжить»;
9) смотреть за сборкой тем.

ОР: строка шага показывает «Тема K / N: <название>», счётчик растёт; если модель
переспрашивает, видно «попытка K / M», при обрыве связи — «связь оборвалась,
пробуем снова: K / M».

10) дождаться конца сборки.

ОР: показано «Что получилось»: название программы, «✻ Собрано за …», «N тем,
X–Y часов», список этапов с первыми темами.

11) нажать «Принять».

ОР: на кнопке ненадолго «Записываю…», затем приложение открывает экран
программы; в списке программ появилась новая, у неё видны этапы и темы.

12) открыть любую тему из новой программы.

ОР: у темы есть материалы, практика и вопросы; экран не показывает ошибок разбора.

## Ветка: провайдер выключен

1) в «Настройках» выключить «Включить провайдера»;
2) вернуться на экран «Программы».

ОР: вместо кнопки сборки написано «Провайдер выключен — включите его в
настройках»; окно сборки не открывается.

## Ветка: программа не прошла проверку

Воспроизводится на слабой модели (маленький контекст, высокая температура).

1) настроить локальную модель с контекстом 8k и температурой выше 1.0;
2) собрать программу и дойти до «Что получилось»;
3) нажать «Принять».

ОР: показан блок «Программа не прошла проверку» со списком причин; программа в
список не добавлена, черновик не потерян.
