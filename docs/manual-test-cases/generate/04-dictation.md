# Диктовка в поле ответа (S141)

Приложение поставлено с речью: `make install-speech`. Для последнего шага нужна
базовая сборка: `make install`. В библиотеке есть программа с открытым этапом,
у этапа есть вопросы зачёта, микрофон подключён.

| # | Действие | Ожидание |
|---|---|---|
| 1 | Открыть этап | у каждого поля «Ваш ответ» кнопка «Надиктовать» |
| 2 | «Уточнить» у абзаца | у поля вопроса тоже «Надиктовать» |
| 3 | «Надиктовать» у первого вопроса зачёта в первый раз | macOS спрашивает доступ к микрофону; после разрешения кнопка называется «Закончить запись» и подсвечена, остальные кнопки диктовки неактивны |
| 4 | Сказать фразу, «Закончить запись» | кнопка на время показывает «Распознаю…», затем текст встаёт в поле, кнопка снова «Надиктовать» |
| 5 | Поставить курсор в середину текста, надиктовать одно слово | слово встаёт в позицию курсора, по пробелу с обеих сторон, курсор стоит после него |
| 6 | Выделить слово, надиктовать другое | выделенное заменено надиктованным |
| 7 | Поправить текст руками, подождать секунду, закрыть и открыть этап | черновик с правкой на месте |
| 8 | «Уточнить» у абзаца, надиктовать вопрос, «Спросить» | над врезкой «Вопрос:» с надиктованным текстом |
| 9 | «Нет» у цепочки, надиктовать продолжение | кнопка есть и у поля продолжения, текст встаёт туда |
| 10 | Начать запись у поля вопроса, нажать «Отмена» | запись снята: остальные кнопки «Надиктовать» снова активны |
| 11 | Начать запись, уйти на главную, вернуться на этап | кнопки активны, новая запись начинается с первого нажатия |
| 12 | Начать запись, промолчать, «Закончить запись» | сообщение «Ничего не распознано — скажите ещё раз», поле не тронуто |
| 13 | Настройки системы → Конфиденциальность → Микрофон: выключить tolearn, «Надиктовать» и «Закончить запись» | сообщение с причиной про микрофон («Микрофон не открылся…» или «Запись пустая…»), поле не тронуто; какое из двух — записать в отчёт |
| 14 | Язык интерфейса English | подписи «Dictate», «Stop recording», «Recognizing…» |
| 15 | Тёмная тема | подсвеченная кнопка записи читается |
| 16 | Базовая сборка, открыть тот же этап, «Уточнить» | кнопки «Надиктовать» нет ни у одного поля |
