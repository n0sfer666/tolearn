# Цикл этапа одним прогоном (S142)

Каждый шаг цикла автотесты держат по отдельности на подставном транспорте. Здесь
цикл проходится целиком в собранном приложении, на одном состоянии: живой
провайдер, настоящая папка практики, буфер обмена, чужой чат и микрофон. Прогон
делает владелец; ветки каждого шага — в кейсах, на которые шаги ссылаются.

**Что нужно:**

- сборка с речью из этой ветки: `make install-speech`;
- чистое состояние (см. [README](../README.md));
- провайдер доведён до зелёного «Пробного запроса»
  ([provider/01-local-model.md](../provider/01-local-model.md)), сеть есть;
- в «Настройках» стоит «Вести журнал запросов» и нажато «Сохранить» — без него в
  журнале нет текста промптов ([provider/04-journal.md](../provider/04-journal.md));
- два пакета, собранные из корня репозитория:

  ```sh
  cargo run -p tolearn-cli --release -- pack examples/chiptune ~/chiptune.tolearn
  cargo run -p tolearn-cli --release -- pack fixtures/v2/valid/nes-dev ~/nes-dev.tolearn
  ```

- пустая папка для практики, например `~/tolearn-practice`;
- любой чат с моделью в браузере;
- микрофон.

У эталона chiptune нет команд проверки, поэтому папка практики и «Запустить»
проверяются на пакете nes-dev: этап «Первый ROM», проверки `ca65 --version` и
`ld65 main.o -C nes.cfg -o game.nes`. Ставить cc65 не обязательно: без него
команда отвечает кодом выхода 127, и по нему видно, что запуск был и что он
вернул.

| # | Действие | Ожидание |
|---|---|---|
| 1 | Перетащить `~/chiptune.tolearn` в окно | «Программа добавлена: Chiptune: музыка звукового чипа NES», карточка в «Библиотеке» |

| 4 | Закрыть приложение, запустить снова, открыть программу | «начат» на месте |

| # | Действие | Ожидание |
|---|---|---|

| 8 | «Выбрать папку», в системном диалоге — папка внутри `~/.local/share/tolearn` | отказ «Эта папка внутри данных приложения — выберите свою.», папка не выбрана |

| 12 | Отметить пункт приёмки, закрыть и открыть этап | галочка и папка практики на месте |
