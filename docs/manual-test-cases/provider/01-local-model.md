# Локальная модель: проверка соединения и пробный запрос

Автотесты ходят в заглушку, а не в настоящий сервер: адрес, версия API, наличие
модели и время ответа проверяются только руками.

**Что нужно:** запущенный локальный сервер — `ollama serve` (порт 11434) либо
`llama-server` (порт 8080, путь `/v1`), и хотя бы одна установленная модель.

## Основной сценарий

1) запустить приложение;
2) перейти в «Настройки»;
3) в карточке «Провайдер модели» включить «Включить провайдера»;
4) в «Вид провайдера» выбрать «Локальная модель»;
5) в «API сервера» выбрать тот, что соответствует запущенному серверу (Ollama или
   OpenAI-совместимый);
6) в поле «Адрес» вписать адрес сервера (`http://127.0.0.1:11434` для Ollama,
   `http://127.0.0.1:8080/v1` для llama-server);
7) в поле «Модель» вписать имя установленной модели;
8) нажать «Сохранить»;
9) нажать «Проверить».

ОР: под кнопками появляется «Соединение есть, моделей: N», где N — число моделей
на сервере; всплывает зелёный тост «сохранено». Рядом с полем «Адрес» стоит
кнопка `(?)` с подсказкой про порты и путь `/v1`.

10) нажать «Пробный запрос».

ОР: пока идёт запрос, видно «Идёт запрос…», кнопки заблокированы; после ответа
появляется «Модель ответила: …» с текстом от модели и «ответил за N с».

## Ветка: сервера нет

1) остановить локальный сервер;
2) в «Настройках» нажать «Проверить».

ОР: красный тост «Провайдер не отвечает»; прошлый результат проверки убран, а не
оставлен как актуальный.

## Ветка: модели нет на сервере

1) поднять сервер обратно;
2) в поле «Модель» вписать имя, которого на сервере нет;
3) нажать «Проверить».

ОР: показано «Выбранной модели на сервере нет — её надо поставить».

## Ветка: совет по моделям

1) открыть блок «Что поставить»;
2) посмотреть список.

ОР: список посчитан по памяти этой машины: у каждой модели указан размер в ГБ и
пометка «пойдёт» либо «тяжеловато для этой машины»; модели, уже стоящие на
сервере, помечены «уже стоит».

3) нажать «Выбрать» у любой модели.

ОР: имя модели подставилось в поле «Модель», список остался на месте.

## Ветка: контекст и температура

1) при Ollama выставить «Контекст, токенов» в 8192, «Температуру» — в 0.2;
2) нажать «Сохранить»;
3) закрыть приложение и запустить снова, вернуться в «Настройки».

ОР: оба значения на месте. При OpenAI-совместимом API поля «Контекст» нет, вместо
неё — строка про ключ `-c` при запуске сервера.
