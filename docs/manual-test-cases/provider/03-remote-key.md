# Внешний сервис: ключ в системном хранилище

Автотесты подменяют хранилище ключей заглушкой. Что ключ реально ложится в связку
ключей ОС, переживает перезапуск и не попадает в файл настроек — проверяется
только руками.

**Что нужно:** рабочий ключ к OpenAI-совместимому API и сеть.

## Основной сценарий

1) запустить приложение;
2) перейти в «Настройки»;
3) в карточке «Провайдер модели» включить «Включить провайдера»;
4) в «Вид провайдера» выбрать «Внешний сервис по HTTP»;

ОР: показано предупреждение, что текст задания и ответ уйдут во внешний сервис
под вашим аккаунтом; рядом с полем «Адрес» есть кнопка `(?)`, в подсказке которой
сказано, что ключ хранится в системном хранилище и его нельзя вписывать в адрес
или в аргументы.

5) заполнить «Адрес» (адрес API вместе с `/v1`) и «Модель»;
6) вписать ключ в поле «Ключ»;
7) нажать «Сохранить».

ОР: тост «сохранено»; поле «Ключ» очистилось, вместо «ключ не задан» показано
«ключ сохранён в системном хранилище».

8) открыть файл `~/.config/tolearn/provider.yaml`.

ОР: в файле есть адрес и модель, но самого ключа нет ни в каком виде.

9) нажать «Проверить», затем «Пробный запрос».

ОР: «Соединение есть, моделей: N», затем «Модель ответила: …» и «ответил за N с».

## Ветка: ключ переживает перезапуск

1) закрыть приложение;
2) запустить снова, перейти в «Настройки»;

ОР: в карточке провайдера снова «ключ сохранён в системном хранилище», поле
«Ключ» пустое.

3) нажать «Пробный запрос», не вводя ключ заново.

ОР: запрос прошёл, модель ответила.

## Ветка: ключ забывают

1) нажать «Забыть ключ»;

ОР: показано «ключ не задан».

2) нажать «Пробный запрос».

ОР: красный тост «Ключ не задан»; запрос наружу не ушёл.

3) открыть системное хранилище (на macOS — Keychain Access, поиск по `tolearn`).

ОР: записи с ключом провайдера там больше нет.

## Ветка: чужой ключ

1) вписать заведомо неверный ключ, нажать «Сохранить»;
2) нажать «Проверить».

ОР: красный тост об ошибке, прошлый результат проверки убран; в блоке отказа
видно, что именно ответил сервис (отказ авторизации), а не общая фраза.
