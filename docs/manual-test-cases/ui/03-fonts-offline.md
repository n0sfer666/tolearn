# Шрифты при выключенной сети

`ui/tests/fonts.test.mjs` проверяет только объявления: шесть файлов на месте, у
каждого своя строка с sha256 в `THIRD-PARTY.md`, обе гарнитуры покрывают
латиницу и кириллицу, у Literata есть курсив. Отрисовку он не видит. Здесь
смотрится то, что видно только глазом в собранном приложении: какой гарнитурой
на самом деле набран экран, нет ли вспышки запасного шрифта и меняется ли
что-нибудь, когда сети нет вовсе.

Раскладка по замыслу: текст этапа, практики и зачёта — Literata (засечная),
весь остальной интерфейс — Golos Text (гротеск), код и `kbd` — системный
моноширинный.

**Что нужно:** собранное приложение и импортированный `chiptune` — как в
[01-screens.md](01-screens.md). Плюс пробник с курсивом: в фикстурах курсива
нет, а курсивное начертание Literata — отдельная пара файлов, и подмену её на
наклонный прямой шрифт видно только на живом экране.

```nu
cp -r examples/chiptune /tmp/chiptune-italic
open --raw /tmp/chiptune-italic/stages/voices.yaml | str replace "**импульсных**" "*импульсных*" | save -f /tmp/chiptune-italic/stages/voices.yaml
cargo run -p tolearn-cli --release -- pack /tmp/chiptune-italic ~/chiptune-italic.tolearn
```

## Подготовка

1) сеть включена, приложение запущено, `chiptune` уже в библиотеке;
2) добавить `~/chiptune-italic.tolearn` через «Выбрать файл».

ОР: тост «Такая программа уже есть — добавлена копия», в библиотеке две
карточки «Chiptune: музыка звукового чипа NES».

## Основной сценарий

1) открыть копию, открыть этап «Голоса чипа», дочитать до конца.

ОР (сеть ещё включена — это снимок для сравнения):

- заголовок этапа и весь текст — засечные, с настоящими засечками и заметно
  более узкими пробелами, чем в шапке;
- шапка, кнопки, поля ввода, подписи под карточками — гротеск без засечек;
- блок с кодом и вывод «Запустить» — моноширинные, знаки стоят колонками;
- слово «импульсных» в первом абзаце — курсивное: у букв «а», «б», «г», «д»
  другие формы, а не наклонённые прямые;
- кириллица везде своя: ни одного «квадратика», ни одной латинской подмены
  вроде узкого «я» из системного шрифта.

2) выйти из приложения, выключить сеть целиком (Wi-Fi и кабель, чтобы не
   осталось ни одного интерфейса), запустить приложение заново, открыть тот же
   этап.

ОР: набор ровно тот же, что в шаге 1, — ни одна буква не изменила ширину,
строки ломаются в тех же местах. Приложение открывается так же быстро, без
паузы на «поиск» шрифтов.

3) следить за первым кадром в момент открытия этапа.

ОР: текст сразу появляется нужной гарнитурой. Вспышка другого шрифта с
последующей перевёрсткой — находка: значит, файл не нашёлся и сработал запасной
стек.

4) не включая сеть, пройти по остальным экранам: библиотека, программа, поиск,
   настройки, помощь, «Новая программа».

ОР: интерфейс везде гротеском, текст этапа и зачёта — засечными, код —
моноширинным; таблица сочетаний в «Помощи» набрана моноширинными клавишами.
Отказ на «Новой программе» говорит про провайдера или сеть — на гарнитуры это
не влияет, они там те же.

5) включить тёмную тему (Настройки → Тема → Тёмная) и вернуться на этап.

ОР: гарнитуры не поменялись, текст не стал тоньше настолько, что читается
хуже, чем в светлой теме.

## Уборка

1) включить сеть обратно;
2) удалить копию «Chiptune: музыка звукового чипа NES» в корзину и очистить
   корзину;
3) удалить `/tmp/chiptune-italic` и `~/chiptune-italic.tolearn`.

ОР: в библиотеке снова одна карточка chiptune, посторонних файлов не осталось.
