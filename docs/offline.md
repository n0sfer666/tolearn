# Офлайн-режим

Свитч «офлайн» выгружает все материалы программы на диск. После этого сеть не
нужна: ссылки в темах открываются из локального архива.

## Что вообще бывает в материалах

Поле `type` у материала уже говорит, как его тянуть:

| `type` | Стратегия |
|---|---|
| `docs` | сначала `llms.txt` / `.md`-вариант, иначе зеркало раздела |
| `article`, `post`, `guide` | monolith → один самодостаточный HTML + читалка |
| `spec`, `rfc` | monolith, обычно уже чистый HTML |
| `repo` | `gix clone --depth 1` |
| `video` | внешний `yt-dlp`, если он есть в системе |
| `paper` | прямая загрузка PDF |

Поле `liveness` — готовый фильтр. `paywall` и `login_required` не тянем вообще:
результатом будет страница логина, а не материал. Показываем как «недоступно
офлайн» честно.

**Чего нет в эталоне.** В `examples/llm-agents-base` встречаются только
`type: docs` (32), `article` (4) и `repo` (1), а `liveness` у всех 37 материалов
равен `ok`. То есть ветки `video`, `paper`, `spec`, а также пропуск по
`paywall`/`login_required` — включая пример отчёта в конце документа — на
единственной имеющейся программе не воспроизводятся. Перечни значений
фиксируются в S02, фикстуры для этих веток создаются там же; до этого считать их
проверенными нельзя.

## monolith

[Y2Z/monolith](https://github.com/Y2Z/monolith) — Rust, лицензия CC0-1.0,
подключается **как библиотека**, не только как CLI. Инлайнит CSS, изображения,
шрифты и скрипты в data-URI и отдаёт один файл HTML5.

Полезные переключатели: `-I` изолировать документ (запрещает любые внешние
запросы через CSP), `-j` выбросить JS, `-v` выбросить видео, `-a` выбросить
аудио, `-b` базовый URL, `-d`/`-B` белый и чёрный список доменов.

Для учебных материалов почти всегда правильно: `-I -j`. JS в архиве статьи не
нужен, а изоляция гарантирует, что сохранённая страница не полезет в сеть.

**Ограничение:** у monolith нет JS-движка. Страница, которая рисует себя на
клиенте, сохранится пустой. Документация проекта предлагает прогонять такие
страницы через Chromium — то есть тащить Chromium.

## Пререндер своим же WebView

Chromium тащить не надо: он уже есть. Tauri работает поверх системного WebView,
и мы можем его использовать как рендерер.

```
открыть скрытое окно с URL
  → дождаться загрузки (событие + таймаут)
  → выполнить document.documentElement.outerHTML
  → передать полученный HTML в monolith как готовый документ
  → закрыть окно
```

Ноль новых зависимостей, ноль дополнительных мегабайт, и ограничение monolith
снято. Скрытое окно живёт по таймауту и не может подвесить очередь.

## Читалка

`dom_smoothie` — Rust-порт readability.js, тот же алгоритм, что в reader mode
браузеров. Даёт заголовок, автора, основной текст. Читалка — это **второй**
слой поверх архива, не замена: если извлечение не удалось, показываем исходный
сохранённый HTML, а не пустой экран.

Рассмотренные альтернативы: `readable-readability` (проще, слабее на сложной
вёрстке), `readability-js` (встраивает QuickJS ради оригинального Mozilla
Readability — лишний движок), `readability-rust`.

## Сайты документации целиком

Сначала пробуем то, что сайт отдаёт сам:

1. `/llms.txt` и `/llms-full.txt` — уже стали фактическим стандартом у
   dev-документации. Это чистый Markdown, идеальный офлайн-формат.
2. Вариант страницы с суффиксом `.md` — многие генераторы документации отдают.
3. `sitemap.xml` — если нужен обход, но хочется знать границы заранее.

Только если ничего нет — краулер. Жёсткие ограничители: тот же домен, глубина по
умолчанию 2, потолок числа страниц, уважение `robots.txt`. Ссылки между
сохранёнными страницами переписываются на локальные.

## Видео

`yt-dlp` не бандлим — см. [ADR-004](adr/004-video-external.md).
Ищем `yt-dlp` и `ffmpeg` в `PATH`:

- нет — кнопка неактивна, рядом объяснение и команда установки для текущей ОС;
- есть — запускаем как внешний процесс, показываем прогресс, даём отменить.

Ограничение по разрешению по умолчанию (720p): лекция на 40 минут в 1080p — это
сотни мегабайт, а читаемость слайдов от этого не меняется.

## Кэш

```
<app-data>/cache/objects/<sha256[0:2]>/<sha256>
<app-data>/cache/index.sqlite
```

Индекс: `url → sha256, type, fetched_at, size, etag, last_modified`.

Адресация по содержимому даёт дедупликацию: один и тот же RFC, упомянутый в трёх
программах, лежит один раз. Кэш живёт **вне** бандла, потому что бандл
перегенерируется, а кэш должен это пережить (ADR-005).

Ревалидация условными запросами по `ETag` / `Last-Modified`. Бюджет диска
настраивается, вытеснение — LRU, объекты из программ с включённым офлайном
защищены от вытеснения.

## Отчёт

Выгрузка обязана заканчиваться честным отчётом, а не «готово»:

```
Скачано     34
Пропущено    6   paywall (4), login_required (2)
Провалено    3   таймаут (2), 404 (1)
```

Провалившиеся повторяются отдельным действием, без перекачивания успешных.
