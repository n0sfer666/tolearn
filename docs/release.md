# Релиз: какой вариант скачивать

Приложение выкладывается двумя вариантами. Это одно и то же дерево исходников,
собранное с одним отличающимся флагом ([ADR-010](adr/010-speech-distribution.md)):
распознавание речи требует локальной модели, а она весит в двадцать раз больше
всего остального приложения, и платить этим весом должен только тот, кому голос
нужен.

| Вариант | Что внутри | Кому |
|---|---|---|
| `tolearn` | всё, кроме распознавания речи | по умолчанию — берите этот |
| `tolearn-with-speech` | плюс whisper.cpp и веса `ggml-small-q5_1` | кто сдаёт зачёт вслух |

Функционально варианты различаются ровно одним экраном. В базовом голосовой
зачёт **виден и неактивен**: кнопка на месте, рядом сказано, что нужен второй
вариант. Всё остальное — программы, темы, практика, конспекты, офлайн-архив,
граф, экспорт — одинаково.

## Сколько весят

Числа — не оценка, а замер: их печатает `scripts/weigh.sh` в джобе `package`
рядом с собранным артефактом, на каждый вариант и на каждую ОС.

| Вариант | ОС | Формат | Вес | Потолок |
|---|---|---|---|---|
| `tolearn` | macOS arm64 | `.dmg` | 8.6 МБ | 12 МБ |
| `tolearn` | Windows x64 | `.msi` | 9.5 МБ | 14 МБ |
| `tolearn` | Linux x64 | `.deb` | 12.8 МБ | 14 МБ |
| `tolearn-with-speech` | macOS arm64 | `.dmg` | 186.5 МБ | потолка нет |
| `tolearn-with-speech` | Windows x64 | `.msi` | 185.8 МБ | потолка нет |
| `tolearn-with-speech` | Linux x64 | `.deb` | 189.0 МБ | потолка нет |

Все шесть чисел — 2026-08-09, версия 0.1.0, все из джобы `package` одного зелёного
прогона. Меняется вес — меняется и эта таблица: она хранит последний замер, а не
первый.

Потолки базового варианта — [бюджеты](architecture.md#бюджеты), и перевес роняет
сборку. У `-with-speech` потолка установщика нет: его вес определяют веса
модели, на которые бюджет назначен отдельно (≤ 192 МБ). Разница между вариантами
— это и есть модель: 190 085 487 байт, внутри установщика, докачивать после
установки нечего.

## Что ставить и как переключиться

Оба варианта — одно приложение с одним идентификатором `dev.tolearn.app`, поэтому:

- **ставить нужно один.** Два установленных варианта спорят за схему `tolearn://`
  и за одно окно; ОС выберет победителя сама, и это будет не тот выбор, о котором
  вас спросили.
- **данные общие и переживают переключение.** Программы, прогресс и конспекты
  лежат вне бандла ([ADR-009](adr/009-user-data-outside-bundle.md)): удалите один
  вариант, поставьте другой — ничего не потеряется.

На macOS `-with-speech` требует 10.15 и новее, базовый обходится 10.13. Планку
поднимает не приложение, а whisper.cpp: он собран на `std::filesystem`, которого
в libc++ до 10.15 нет.

Установщик регистрирует схему `tolearn://` сам: ссылка вида
`tolearn://topic?roadmap=<программа>&topic=<тема>` открывает нужную тему в уже
работающем приложении.

## Собрать варианты самому

Из одного дерева, отличие — один флаг:

```sh
cd app
cargo tauri build                                                   # tolearn
cargo tauri build --features speech --config tauri.with-speech.conf.json
```

Второй команде нужны сабмодуль `speech/vendor/whisper.cpp` и файл
`app/models/ggml-small-q5_1.bin` — веса, которые попадут в установщик ресурсом.
Взвесить собранное: `sh scripts/weigh.sh target/release/bundle base` (или
`with-speech`).
