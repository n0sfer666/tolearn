# Руководство пользователя

**Русский** · [English](../en/guide.md)

Коротко: как пользоваться приложением. Установка — в
[install/](install/README.md).

## С чего начать

1. Получите программу обучения. Промпты для этого лежат в репозитории —
   [`core/assets/generate-roadmap.md`](../../core/assets/generate-roadmap.md)
   даёт скелет программы, а
   [`core/assets/generate-topic.md`](../../core/assets/generate-topic.md) — файл
   одной темы: скопируйте первый в любой чат с LLM, допишите под ним, чему
   хотите научиться, заберите `roadmap.yaml` и `progress.yaml`, а затем вторым
   промптом соберите темы по одной. Получится бандл — папка с `roadmap.yaml`,
   `topics/*.yaml` и `examiner.md`. Пример —
   [`examples/llm-agents-base`](../../examples/llm-agents-base). Кнопки «взять
   промпт» в интерфейсе пока нет.
2. На главном экране нажмите «Выбрать папку» или «Выбрать архив». Приложение
   проверит бандл и покажет ошибки, если они есть.
3. Откройте тему и начинайте.

## Экраны

| Экран | Зачем |
|---|---|
| Программа | все темы по этапам, статусы, точка входа в тему |
| Тема | материалы, практика, вопросы |
| Практика | задание, ограничения и приёмка; команды проверки запускаются по нажатию |
| Зачёт | вопросы, ответы и вердикт |
| Поиск | по темам и материалам открытой программы |
| Настройки | язык, провайдер LLM, офлайн |

## Зачёт

Два пути, оба ваши:

- **Копипаст (по умолчанию).** Приложение собирает промпт, вы вставляете его в
  любой чат, ответ модели вставляете обратно. Ни ключа, ни аккаунта.
- **Провайдер.** В настройках можно указать Ollama (локально) или
  OpenAI-совместимый адрес с ключом. Ключ хранится в системном хранилище ОС.

Вердикт пишется в `progress.yaml` вашей программы. Больше приложение в бандл не
пишет ничего.

## Офлайн

Материалы темы скачиваются один раз и сохраняются целиком одним HTML-файлом.
После этого сеть не нужна: читалка показывает текст из архива. Ничего, кроме
явно запрошенной загрузки, в сеть не ходит.

## Где лежат данные

- Программы — там, где вы их положили; приложение помнит путь в реестре.
- Настройки, реестр программ и хранилище (архивы страниц) — в
  `~/.config/tolearn` и `~/.local/share/tolearn`, одинаково на всех трёх ОС;
  точные пути и как их перенести —
  [install/](install/README.md#где-лежат-ваши-данные).
- Удаление приложения данные не трогает.
- Программы v2 приложение держит в своей библиотеке, в
  `~/.local/share/tolearn/programs/`. Данные программ v1 — реестр
  `~/.config/tolearn/registry.yaml` и в `~/.local/share/tolearn` каталоги
  `unpacked/`, `history/`, `offline/` и индекс поиска `search-*` — после
  перехода на v2 приложение не читает и само не удаляет: их можно удалить
  руками.

## Экспорт

Кнопка «Экспорт в Markdown» на экране программы собирает всю программу в один
файл — с оглавлением и темами. Ответы и ловушки попадают в файл только для
зачтённых тем. Внутрь самого бандла экспорт не пишет.
