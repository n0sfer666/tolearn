# Установка

**Русский** · [English](../../en/install/README.md)

Приложение ставится готовым установщиком под свою ОС либо собирается из
исходников. Ставить нужно **один** вариант — `tolearn` или
`tolearn-with-speech`: чем они отличаются, сказано в
[release.md](../release.md).

| ОС | Что скачивать | Страница |
|---|---|---|
| macOS (Apple Silicon) | `.dmg` | [macos.md](macos.md) |
| Windows 10/11, x64 | `.msi` | [windows.md](windows.md) |
| Linux, Debian/Ubuntu, x64 | `.deb` | [linux.md](linux.md) |
| Любая из трёх | сборка из исходников | [source.md](source.md) |

Сборок под Intel-Mac, ARM-Linux и 32-битные системы нет: CI собирает ровно шесть
установщиков — два варианта на три ОС. На всём остальном железе остаётся
[сборка из исходников](source.md).

## Установщики не подписаны

Ни сертификата Apple, ни сертификата Authenticode у проекта нет, поэтому и
macOS, и Windows при первом запуске скажут, что разработчик не проверен. Это
ожидаемо и не означает, что с файлом что-то не так; как пройти предупреждение —
на странице своей ОС. Обход предупреждения — осознанное действие: делайте его
только для файла, скачанного со [страницы релизов](https://github.com/n0sfer666/tolearn/releases)
этого проекта.

## Где лежат ваши данные

Одинаково на всех трёх ОС — приложение не раскладывает их по-своему в каждой
системе:

| Что | Путь |
|---|---|
| Настройки, провайдер, реестр программ | `~/.config/tolearn` |
| Конспекты, архивы страниц, распакованные бандлы, история | `~/.local/share/tolearn` |

На Windows `~` — это `C:\Users\<имя>`, то есть `C:\Users\<имя>\.config\tolearn`.
Переменные `XDG_CONFIG_HOME` и `XDG_DATA_HOME` уважаются, если заданы абсолютным
путём. Сами программы обучения лежат там, где вы их положили: приложение хранит
не их, а путь к ним.

Данные не привязаны ни к варианту сборки, ни к способу установки: перенос с
`tolearn` на `tolearn-with-speech`, переустановка и переезд с установщика на
сборку из исходников их не трогают. Если вы ставили раннюю версию, которая
хранила всё в каталоге приложения ОС (`dev.tolearn.app`), первый запуск новой
перенесёт файлы сам.

## Удаление

Удаление приложения не удаляет данные — это отдельное действие:

```sh
rm -rf ~/.config/tolearn ~/.local/share/tolearn
```

Конспекты во внешнем хранилище (папка Obsidian и любой другой заданный каталог)
лежат вне этих путей, и удалять их нужно самому — приложение туда не полезет.
