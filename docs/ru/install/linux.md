# Установка на Linux

**Русский** · [English](../../en/install/linux.md)

Готовый пакет собирается один: `.deb` под x64 — то есть Debian, Ubuntu и
производные. Для остальных дистрибутивов и для ARM остаётся
[сборка из исходников](source.md).

## Зависимости

Интерфейс рисует WebKitGTK, поэтому в системе должны быть его рантайм-библиотеки.
`apt` подтянет их сам, если ставить пакет через него (см. ниже); поставить
заранее:

```sh
sudo apt update
sudo apt install libwebkit2gtk-4.1-0 libgtk-3-0
```

Варианту `tolearn-with-speech` нужен ещё ALSA (`libasound2`) — он есть в любой
десктопной системе; если микрофон не виден, поставьте пакет явно.

## Как поставить

1. Скачайте со [страницы релизов](https://github.com/n0sfer666/tolearn/releases)
   один файл: `tolearn_<версия>_amd64.deb` либо
   `tolearn-with-speech_<версия>_amd64.deb`. Оба ставить нельзя — они спорят за
   схему `tolearn://`.
2. Поставьте пакет вместе с зависимостями:

   ```sh
   sudo apt install ./tolearn_<версия>_amd64.deb
   ```

   `dpkg -i` тоже сработает, но зависимости придётся доставлять руками
   (`sudo apt -f install`).
3. Приложение появится в меню как `tolearn`; из терминала запускается командой
   `tolearn`.

Подписи у пакета нет — `apt` не проверяет его ключом, вы ставите файл, которому
доверяете сами. Скачивайте только со страницы релизов проекта.

## Если окно пустое или не открывается

Почти всегда это WebKitGTK. Запустите из терминала и посмотрите на вывод:

```sh
tolearn
```

- ошибка про `libwebkit2gtk-4.1.so` — зависимость не встала, вернитесь к первому
  шагу;
- пустое белое окно на драйверах Nvidia и в некоторых VM лечится отключением
  аппаратного ускорения композитинга:

  ```sh
  WEBKIT_DISABLE_COMPOSITING_MODE=1 tolearn
  ```

  Помогло — пропишите переменную в свой `.desktop`-файл или в окружение сессии.

## Проверить, что всё работает

Запустите приложение: должно открыться окно с главным экраном и кнопками
«Выбрать папку» / «Выбрать архив». Дальше — [руководство](../guide.md).

Проверить, что зарегистрировалась схема ссылок (приложение при этом должно быть
запущено):

```sh
xdg-open "tolearn://topic?roadmap=demo&topic=demo"
```

Приложение выйдет на передний план. Что программы `demo` нет — нормально,
проверяется сама обработка ссылки.

## Обновление и удаление

Обновление — поставить новый `.deb` той же командой, он заменит установленный.
Удаление:

```sh
sudo apt remove tolearn
```

Ваши данные при этом остаются, где лежали
([где именно](README.md#где-лежат-ваши-данные)).
