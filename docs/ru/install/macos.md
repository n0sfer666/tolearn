# Установка на macOS

**Русский** · [English](../../en/install/macos.md)

Нужен Mac на Apple Silicon (M1 и новее): собирается только `aarch64`-сборка,
Intel-версии нет. Минимум системы — macOS 10.13, для варианта
`tolearn-with-speech` — 10.15 (планку поднимает whisper.cpp, а не приложение).

## Как поставить

1. Скачайте со [страницы релизов](https://github.com/n0sfer666/tolearn/releases)
   один файл: `tolearn_<версия>_aarch64.dmg` либо
   `tolearn-with-speech_<версия>_aarch64.dmg`. Оба ставить нельзя — они спорят за
   схему `tolearn://`.
2. Откройте `.dmg` двойным щелчком и перетащите `tolearn` в «Программы».
3. Образ можно извлечь и удалить — приложение уже скопировано.

## Первый запуск: «Apple не может проверить приложение»

Приложение подписано ad-hoc — то есть без сертификата Apple и без
нотарификации. Первый запуск скачанного файла Gatekeeper прервёт диалогом
«tolearn не открыт: Apple не может проверить, что приложение не содержит
вредоносного ПО» с кнопками «Переместить в Корзину» и «Готово». Порядок:

1. В диалоге нажмите **«Готово»** — не «Переместить в Корзину».
2. Откройте «Системные настройки» → «Конфиденциальность и безопасность» и
   пролистайте до раздела «Безопасность»: там появится строка про
   заблокированный `tolearn` и кнопка **«Открыть всё равно»**.
3. Подтвердите паролем или Touch ID и в следующем диалоге нажмите «Открыть».

Дальше приложение запускается обычным двойным щелчком: решение запоминается.
Щелчок правой кнопкой → «Открыть» в свежих версиях macOS обхода больше не даёт —
идите через настройки.

Делайте это только для файла, скачанного со страницы релизов проекта.

## Проверить, что всё работает

Запустите приложение: должно открыться окно с главным экраном и кнопками
«Выбрать папку» / «Выбрать архив». Дальше — [руководство](../guide.md).

Проверить, что зарегистрировалась схема ссылок (приложение при этом должно быть
запущено):

```sh
open "tolearn://topic?roadmap=demo&topic=demo"
```

Приложение выйдет на передний план. Что программы `demo` нет — нормально,
проверяется сама обработка ссылки.

## Обновление и удаление

Обновление — тот же порядок: скачать новый `.dmg` и заменить приложение в
«Программах». Удаление — перетащить `tolearn` в корзину; ваши данные при этом
остаются, где лежали ([где именно](README.md#где-лежат-ваши-данные)).
