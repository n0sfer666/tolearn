# Установка на Windows

**Русский** · [English](../../en/install/windows.md)

Нужна Windows 10 или 11, x64. Приложение рисует интерфейс в системном WebView2:
в Windows 11 он есть всегда, в Windows 10 обычно тоже — если его нет,
установщик поставит его сам.

## Как поставить

1. Скачайте со [страницы релизов](https://github.com/n0sfer666/tolearn/releases)
   один файл: `tolearn_<версия>_x64_en-US.msi` либо
   `tolearn-with-speech_<версия>_x64_en-US.msi`. Оба ставить нельзя — они спорят
   за схему `tolearn://`.
2. Запустите `.msi` двойным щелчком и пройдите мастер. Права администратора не
   нужны, если ставите для текущего пользователя.
3. Приложение появится в меню «Пуск» под именем `tolearn`.

## Первый запуск: SmartScreen

Установщик не подписан сертификатом Authenticode, поэтому SmartScreen покажет
синее окно «Система Windows защитила ваш компьютер». Обход: «Подробнее» →
«Выполнить в любом случае». Делайте это только для файла, скачанного со страницы
релизов проекта.

Антивирус может дополнительно задержать `.msi` на проверку — это ожидаемо для
неподписанного установщика.

## Проверить, что всё работает

Запустите `tolearn` из меню «Пуск»: должно открыться окно с главным экраном и
кнопками «Выбрать папку» / «Выбрать архив». Дальше — [руководство](../guide.md).

Проверить, что зарегистрировалась схема ссылок (приложение при этом должно быть
запущено), в PowerShell:

```powershell
Start-Process "tolearn://topic?roadmap=demo&topic=demo"
```

Приложение выйдет на передний план. Что программы `demo` нет — нормально,
проверяется сама обработка ссылки.

## Обновление и удаление

Обновление — запустить новый `.msi`, он заменит установленную версию.
Удаление — «Параметры» → «Приложения» → `tolearn` → «Удалить»; ваши данные при
этом остаются, где лежали ([где именно](README.md#где-лежат-ваши-данные)).
