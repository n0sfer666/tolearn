# Фикстуры

Эталон формата ([docs/format.md](../docs/format.md)) — программа
[`examples/chiptune/`](../examples/chiptune/). Она главная фикстура и главный
источник правды по форме и не меняется: ветка, которой в ней нет, добавляется в
[`v2/`](#v2), а не подкручивается в эталоне.

```
v2/            корпус схем и чтения программ
valid/page/    сохранённая страница с картинкой, стилем и скриптом (offline/tests/page.rs)
valid/reader/  страницы разной разметки для извлечения текста (offline/tests/reader.rs)
openlibrary/   записанные ответы search.json: по ISBN, по названию, не найдено, обрезанный (offline/tests/book.rs)
commons/       записанные ответы API Commons: свободный файл, несвободные, несвободный выше свободного, не найдено, обрезанный (offline/tests/commons.rs, generate/tests/images.rs)
generate/plan/ ответы модели на карту: плоская, раздробленная, битая, подпрограмма (generate/tests/plan.rs)
audio/{ru,en}/ корпус распознавания речи S55 (speech/tests/corpus.rs)
```

## v2/

```
v2/valid/<программа>/           программы целиком: program.yaml, stages/, assets/, children/
v2/broken/{program,stage}/      документы, которые схема обязана отвергнуть
v2/strict/{program,stage}/      документы, которые схема принимает, а чтение (S99) отвергает
v2/invalid/<код>__<что>/        деревья программ, нарушение в которых видно только между файлами
```

`valid/` — раскладка **по программам**, а не по видам документа: гейт обходит
каталог программы вместе с `children/`, и так же проверяет, что ассет из блока
лежит в `assets/` своей программы. `valid/nes-dev/` — дерево глубиной три: узел,
узел, лист. У листа два этапа: `first-rom` несёт практику с `check` и задание
блоками всех шести видов, `linker` — минимальный этап, от которого сняты битые
копии. Блок задания повторяет текст блока этапа, и его `id` показывает суффикс
`-2`: `blocks` и `practice.task` — одна последовательность. В `blocks` этапа
`first-rom` есть картинка с `source`: без неё `gate::parser` нечем доказать, что
`source` блока этапа читается. У корня вторая строка `map.children` без
каталога — подпрограмма, которой ещё нет: чтение её пропускает, а не падает.

Гейт `every_fixed_value_appears_in_the_valid_corpus` требует, чтобы каждое
значение из каждого `enum` и `const` обеих схем встречалось в эталоне или в
`valid/`. Добавили значение в схему — добавьте документ, который его несёт.

`id` блоков в эталоне и в `valid/` посчитаны функцией S97, гейт
`every_block_id_in_the_valid_corpus_is_the_s97_id_of_its_text` сверяет их. Правка
текста блока требует нового `id`: гейт печатает ожидаемый список, из него его и
берут.

## v2/broken/

Имя файла — `<код>__<что сломано>.yaml`, где код — нарушенное ключевое слово
JSON Schema. Фикстура обязана давать **ровно одну** ошибку — тест сравнивает
список кодов валидатора со списком из одного элемента, заявленного в имени.
Поэтому битая фикстура — это полная копия валидного документа с одной правкой:
любое второе расхождение со схемой сломало бы «ровно одну ошибку». Код в имени —
тот, который выдаёт валидатор, а не тот, который логичнее.

Битые копии правил `program` сняты с `examples/chiptune/program.yaml`, правил
`stage` — с `valid/nes-dev/…/stages/linker.yaml`. Правка схемы, меняющая базу,
требует правки копий: гейт «ровно одна ошибка» падает именно на той копии,
которая отстала, и называет её путь. Гейт
`every_rule_of_a_schema_has_a_broken_fixture` требует копию на **каждое**
ключевое слово обеих схем: добавили в схему правило нового вида — добавьте
фикстуру, которая его нарушает. Пол — двенадцать **разных** кодов, сейчас их
тринадцать на двадцати трёх фикстурах.

## v2/strict/ и v2/invalid/

`strict/` — документы, которые схема принимает, а чтение отвергает. Тест
`every_strict_document_is_refused_by_its_own_rule` (`core/tests/program_tree.rs`)
держит таблицу «файл → код» и требует ровно одно нарушение, а
`every_strict_document_is_pinned_to_its_rule` — чтобы в таблице был каждый файл
каталога: новая strict-копия без строки в таблице роняет тест.

`invalid/<код>__<что сломано>/` — дерево программы, нарушение в котором видно
только между файлами: глубина, повтор UUID, каталог подпрограммы или файл этапа
с чужим идентификатором, ассет, которого нет, ошибка разбора этапа. `load` и
`validate` вместе дают ровно одну ошибку, и её код стоит в имени каталога.
