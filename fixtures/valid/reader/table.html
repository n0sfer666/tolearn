Владение

Владение в Rust — это правило, по которому у каждого значения есть ровно один владелец. Когда владелец выходит из области видимости, значение освобождается, и делать это вручную не нужно. Заимствование даёт временный доступ к значению без передачи владения: ссылок для чтения может быть много, ссылка для записи — только одна, и одновременно с чтением она существовать не может. Проверку выполняет компилятор, поэтому гонки по памяти отсекаются до запуска программы. Время жизни ссылки не может превышать время жизни значения, на которое она указывает, — это и есть тот инвариант, который в языках со сборщиком мусора поддерживается во время выполнения, а в Rust проверяется статически.
